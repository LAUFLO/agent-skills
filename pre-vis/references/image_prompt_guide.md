## 1. 图片提示词通用结构

每条图片提示词按以下顺序组织，缺一不可：

```
[主体] → [姿态/动作] → [环境/背景] → [构图/机位] → [光线/色调] → [风格/画幅] → [@N 参考图约束]
```

**示例**：
> 一个17岁少年，黑色短发带银色发夹，穿校服外套，低头手持旧怀表，站在冷蓝色走廊中，
> 地面有雨水反光，中景固定机位，冷蓝调柔光，日系2D赛璐珞动画风格，16:9画幅
> @1=c01_v1.png（主角校服变体） @2=s01_scene.png（场景参考）

## 2. 角色定妆照提示词（三层结构）

### 2.1 基础定妆照（`base_ref_image`，每角色生成**两张**：身体三视图 + 头部特写，2026-09-13 定规）

**作用**：角色默认面部/发型/体型指纹，是**不可变锚点**，第一集生成后永远有效。
**双卡结构（防面部漂移）**：身体三视图里头部占比仅 5~8%，面部锚点有效像素不足——拆成"身体三视图（颈上裁切，不画头）+ 头部特写三格（放大 5~8 倍）"，各锚各的：身体卡锁体型/服饰，头部卡锁面部/发型。

**生成时机**：角色首次出现时生成一次。角色形象重大变化时用 `base_versions` 新增版本，**不修改此文件**。

**feature_anchors 选取判据**（阶段 ① 写角色时选 2~4 个）：
- 选择优先级：**辨识度 > 稳定性**——选"不看脸也能认出是这个角色"的 2~4 个特征（泪痣 / 发夹 / 特殊发型 / 体型），不是面部特征全列
- 必须**稳定**：跨镜头不变化的才入选；表情/姿态相关的（"爱皱眉"）不入选
- 不含服饰（服饰走 `costume_variants`），否则一致性检查失效
- **头部特写须按格分配锚点**：正面格 = 眼形/泪痣/眉形；侧面格 = 眼耳距/鼻梁/下颌线/发型侧走向；背面格 = 发型背走向/发际线/后颈

**卡片 1：身体三视图（`c01_base.png`）**
```
[角色名]，[年龄]，整身三视图（正面/侧面/背面并排），**颈部以上裁切（不画头部）**，
[体型描述]，
白色素T恤（素衣状态，不穿剧情服饰），
[体型相关 feature_anchors，用顿号分隔]，
浅灰色纯色背景，均匀正面柔光，
[完整 ⑧ 风格块]，2:1 横版画幅
```

**卡片 2：头部特写三格（`c01_head.png`，面部一致性主锚）**
```
[角色名] 头部特写，三格并排（正面/侧面/背面，每格头部占 40~60%），
[发型 + 发色全量（正面/侧面/背面各自走向）]，
[feature_anchors 全量，逐格标注出现位置：正面格 = 眼形/泪痣/眉形，侧面格 = 眼耳距/鼻梁/下颌线，背面格 = 发型背走向/发际线]，
中性半表情（闭嘴 + 睁眼 + 轻微生气感；**不锁死单一表情**，表情多样性由表情设定组承担），
浅灰色纯色背景，均匀柔光，
[完整 ⑧ 风格块]，约 1:1.2 横版画幅
@1=c01_base.png（体型/肩宽一致性）
```

**示例**（双卡）：
> c01_base：林晨，17岁男生，整身三视图（正面/侧面/背面并排），**颈部以上裁切（不画头部）**，
> 偏瘦体型，白色素T恤（素衣状态），银色发夹（挂于衣领），
> 浅灰色纯色背景，均匀正面柔光，日系2D赛璐珞动画风格，2:1横版画幅
> c01_head：林晨 头部特写，三格并排（正面/侧面/背面，每格头部占 50%），
> 黑色短发（正面齐刘海 / 侧面鬓角短 2cm / 背面发旋偏左后），
> 银色发夹（正面格左侧）、左眼角泪痣（正面格）；侧面格 = 眼耳距适中/鼻梁平直/下颌线柔和；背面格 = 发旋偏左后/发际线 M 形，
> 中性半表情（闭嘴 + 睁眼 + 轻微生气感），浅灰色纯色背景，均匀柔光，
> 日系2D赛璐珞动画风格，1:1.2横版画幅，@1=c01_base.png（体型约束）

**参考图文件名**：`c01_base.png`（身体）+ `c01_head.png`（头部，**面部一致性主锚，@N 优先级高于场景图**）

### 2.2 服饰变体（`costume_variants[].ref_image`，每个 variant 生成一张）

**生成时机**：该 variant **首次使用单元**生成一次，后续集直接引用文件不重新生成。

```
[角色名]，[年龄]，整身三视图（正面/侧面/背面并排），**颈部以上裁切（不画头部，头部以 c01_head 为准）**，
[体型描述]，
[服饰变体描述：外层→内层→下装→鞋子]，
[体型相关 feature_anchors 全量]，
浅灰色纯色背景，均匀正面柔光，
[完整 ⑧ 风格块]，2:1 横版画幅
@1=c01_base.png（体型/肩宽约束） @2=c01_head.png（面部/发型约束，强制一致）
```

**示例**（c01_v1 校服变体）：
> 林晨，17岁男生，整身三视图（正面/侧面/背面并排），**颈部以上裁切（不画头部，头部以 c01_head 为准）**，
> 偏瘦体型，
> 黑色校服外套、白色卫衣、深蓝色运动裤、黑色帆布鞋，
> 银色发夹（挂于衣领），
> 浅灰色纯色背景，均匀正面柔光，
> 日系2D赛璐珞动画风格，2:1横版画幅
> @1=c01_base.png（体型约束） @2=c01_head.png（面部/发型约束）

**示例**（c01_v2 西装变体）：
> 林晨，17岁男生，整身三视图（正面/侧面/背面并排），**颈部以上裁切（不画头部，头部以 c01_head 为准）**，
> 偏瘦体型，
> 深灰色西装、白衬衫、黑色皮鞋，
> 银色发夹（挂于衣领），
> 浅灰色纯色背景，均匀正面柔光，
> 日系2D赛璐珞动画风格，2:1横版画幅
> @1=c01_base.png（体型约束） @2=c01_head.png（面部/发型约束）

**关键**：每个 variant 提示词中 `feature_anchors`（体型相关部分）和体型描述必须与 base 完全一致，只替换服饰部分；**面部/发型描述不写进 variant 提示词**（由 @2 head 卡承载，文字重复会稀释约束）。

**@1/@2 选择规则**：variant 生成时 @1 = 该 variant **首次使用单元**当前生效的 base（有 `base_version` 时用 base_version 的 ref_image，否则用 `base_ref_image`）；**@2 = 对应生效版本的头部特写（`c01_head.png` 或 `c01_head_longhair.png`）**——面部/发型约束走 head 卡，不靠 variant 图自身。

### 2.3 基础形象变体（`base_versions[].ref_image`，每个 version 生成一张）

**作用**：角色阶段性形象变化（换发型、体型变化、特殊化妆）的参考图，只在 `active_episodes` 范围内生效，超出后自动回落到 `base_ref_image`。

**生成时机**：该 version **首次使用单元**生成一次，后续集直接引用文件不重新生成。

```
[角色名]，[年龄]，整身三视图（正面/侧面/背面并排），**颈部以上裁切（不画头部，头部以对应版本 head 卡为准）**，
[新的发型+发色]，[新的体型描述（如有）]，
白色素T恤（素衣状态），
[feature_anchors 中不变的部分]，
浅灰色纯色背景，均匀正面柔光，
[完整 ⑧ 风格块]，2:1 横版画幅
@1=[base_ref_image 文件名]（体型约束） @2=[对应版本 head 卡文件名]（面部/发型约束，强制同一角色）
```

**示例**（c01_bv2 长发版）：
> 林晨，17岁男生，整身三视图（正面/侧面/背面并排），**颈部以上裁切（不画头部）**，
> 偏瘦体型，
> 白色素T恤（素衣状态），
> 浅灰色纯色背景，均匀正面柔光，
> 日系2D赛璐珞动画风格，2:1横版画幅
> @1=c01_base.png（体型/肩宽约束） @2=c01_head.png（面部锚点约束；**发型部分按新版本文字：黑色长发至肩，右侧扎小马尾**）

**参考图文件名**：`c01_base_longhair.png`（**发型变化时同步重出该版本头部特写 `c01_head_longhair.png`**）

**回退规则**：`active_episodes` 结束后（如 episode_02 结束后），后续镜头 @1 自动回落到 `c01_base.png` + @2 回落到 `c01_head.png`，**不重新生成**，直接使用原文件。

### 2.4 单视图（特定表情/场景时需要）

```
[角色名]，[姿态/表情]，[当前 variant 的服饰描述]，[feature_anchors 全量]，
[背景：引用场景图描述]，[光线]，[风格]，[画幅]
@1=[对应 variant 的 ref_image 文件名]（体型+服饰约束） @2=[当前生效版本的 head 卡，如 c01_head.png / c01_head_longhair.png]（面部主锚）
```

**注意**：单视图必须带 `@1=variant_ref_image`，确保与服饰变体参考图一致。

```

### 2.8 色板约束（角色/场景/道具均适用）

在提示词末尾加色彩约束，防止 AI 生成时颜色漂移：

```
色彩约束：
- 主色：[色名] [hex值]（如"灰褐色 #6D6B69"）
- 辅色：[色名] [hex值]
- 点缀色（可选）：[色名] [hex值]
- 整体色调：[偏冷/偏暖/中性]
```

**写入位置**：
- 角色定妆照 → 写入 §2.1/§2.2 提示词末尾
- 场景图 → 写入 §3 提示词末尾
- 道具图 → 写入 §4 提示词末尾

**示例**：
> 色彩约束：主色 灰褐 #6D6B69 / 辅色 土黄 #BDAE9A / 点缀 暗棕 #BD7A66，整体色调偏暖土色

## 3. 场景图提示词

```
[场景名]，[时间]，[空间布局简述]，[氛围关键词]，
[光线：色温+光源位置]（查风格块 S5 光色参数表 + 场景 lighting 字段），[主要元素（3~5个，按重要性排序，材质查 S2）]，
无人物（或人物占比<20%），
[完整 ⑧ 风格块（非关键词串）]，16:9电影画幅，@1=style_ref（风格定板）
```

**示例**（光源三要素写全）：
> 学校教学楼走廊，夜晚，走廊两侧封闭教室门，地面有雨水渗入，
> 冷蓝荧光灯从天花板上方照射，8000K，暗:亮比 70:30，远处窗外暖黄光斑 3200K，
> 地面湿滑反光，天花板悬挂旧式日光灯管，走廊尽头有安全出口指示灯（绿色），
> 无人物，日系2D赛璐珞动画风格（完整 ⑧ 块），16:9电影画幅，@1=style_ref_01.png

**S 槽位路由（双层风格锁，2026-09-13）**：
- 场景图 = **S5 光色参数 + S2 道具材质** + 完整 ⑧ 块 + ⑨ 负向，@1=风格定板（style_ref，E01 出一次跨集复用）
- 角色定妆照 = **S1 人物外观**（头身比/眼型/线宽/皮肤/发丝/表情档）+ 完整 ⑧ 块；灰底资产图可不带 style_ref
- 道具图 = **S2 道具材质**（材质渲染 + 高光交互 + 风格典型道具）+ 完整 ⑧ 块
- 全部查表 = `素材库/风格提示词/README.md`"阶段→槽位速查表"；取值只允许在基线（`series.json` `style_baseline`）槽内，禁表外发明；**参数锁级（L1 全片硬锁 / L2 幕级锁 / L3 镜头级自由）以 `style_baseline[].lock` 标签为准，L1 项任何阶段不可改**

**原则**：
- 场景图是参考底图，尽量无人物（或人物占比 < 20%），避免带入错误角色形象
- 光线/色调必须与 `script.json` 中该场景的 `time` 和 `lighting` 字段一致
- 3~5 个主要元素的**重要性排序判据**：叙事功能 > 氛围 > 装饰（镜头中的关键道具/事件发生位置排最前，氛围元素（雨/雾/光斑）居中，装饰细节最后）
- 画幅 16:9，构图留白给人物活动空间

**光源决策依据**（写提示词前先定光，三步）：
1. **物理上可能**：故事的 `time` + `location` 里实际存在什么光源（夜晚走廊 = 荧光灯 + 窗外灯光，不是日光）
2. **情绪上匹配**：场景 `atmosphere` 字段映射到色温（孤独夜 = 冷蓝 8000K；温暖的家 = 暖黄 3200K）
3. **系列一致性**：同一场景跨多集，基线光源不变；明暗比可随集数变化（随角色弧线推进，见 `video_prompt_guide.md` §1.4 Step 4）

**光源具体化规则**（场景图提示词必须写全三要素）:

| 要素 | ❌ 模糊写法 | ✅ 具体写法 |
|------|----------|----------|
| 光源位置 | "自然光" | "来自左侧窗户的自然光" |
| 色温 | "暖色" | "暖黄色 3200K，来自天花板吊灯" |
| 强度/比例 | "亮" | "暗:亮比 70:30，主光源在角色面部左侧" |

> 行业共识："Specify the light source, not the adjective"。写光源位置 + 色温数值 + 明暗比，不写形容词。

## 4. 道具图提示词（设定包）

### 4.1 主体图（每个道具 1 张，必生成）

```
[道具名]，[材质/颜色/尺寸]，[关键特征（磨损/裂纹/刻字等）]，
[拍摄角度（俯视/45度/正侧）]，
浅灰色纯色背景，均匀柔光，
[全集风格词]，1:1画幅
色彩约束：主色 [hex] / 辅色 [hex]
```

**示例**：
> 旧怀表，铜质外壳，表面氧化发绿，细密划痕，表盘玻璃裂纹，
> 指针停在23:15位置，45度俯拍，
> 浅灰色纯色背景，均匀柔光，日系2D赛璐珞动画风格，1:1画幅
> 色彩约束：主色 氧化绿 #4A7A6B / 辅色 暗铜 #8B6B4A

**参考图文件名**：`p01_prop.png`

### 4.2 细节特写（有标志性格外特征的道具生成）

```
[道具名]局部特写 2×2 网格：
左上：[最关键的细节，如"表盘裂纹+指针"]
右上：[材质/纹理细节，如"外壳氧化绿锈纹理"]

## 5. 分镜批图版（scene storyboard grid，场景级整场审阅）

**用途**：把同一场景 3~6 个镜头并排生成在**一张图**里，用于逐镜首帧生成**之前**的整场占位/景别/轴线审阅（Boords "deck" 模型：board 层改稿最便宜，生成层最贵）。**只用于审阅，不进入视频生成**。

**生成时机**：阶段 ③ 提示词写定并确认 → 用户按场景生成批图版 → 4 项审阅通过 → 再逐镜生成首帧。不过 → 回 ①/③ 改站位/景别后重新出批图版，**不生成首帧**。

**面板数**：一图 3~6 镜（不超过 6，9 格以上单格分辨率被稀释，视频模型会丢角色/光线细节——行业实测 3 格组比 9 格组稳定）。同场景镜头 >6 时按幕拆两张。

**画幅**：3 镜 → 1×3（3:1）；4 镜 → 2×2（1:1）；5~6 镜 → 3×2（3:2）。

**提示词结构**：

```
[场景名] 分镜 N 格并排（左→右、上→下 = shot 顺序，每格标注 shot 编号），
格 1（shot_011）：[角度/景别 + 主体位置 + 站位要点，如：平视 中景，林晨中景偏左低头，秤前景右侧虚化]，
格 2（shot_012）：[...]，
格 3（shot_013）：[...]，
同图同角色（[feature_anchors 全量] + [当前 variant 服饰]）、同一光线（[光源三要素]），
角色站位跨格连续（左右位置不互换，180° 轴线），景别递进 [中→近→特 等]，
[全集风格词]，[画幅]
@1=[角色参考图] @2=[场景图]
```

**文件名**：`episode_NN/storyboards/sNN_grid.png`（每场景一张）。多单元复用同场景且本单元无新增景别/站位变化时**不重出**；有变化则本单元重出一张。

**4 项审阅（用户确认点；不过 → 回 ①/③ 改站位/景别后重新出图）**：

| 检查 | 通过标准 |
|------|---------|
| 角色一致 | 每格角色 feature_anchors 数得出来，面部/发型无漂移 |
| 站位连续 | 同场景各格角色左右/前后关系不互换（§2.8 基线）；对话戏 OTS 前景肩位一致 |
| 景别序列 | 与 §2.11 一致：无连续同级景别；升级处切近、退潮处切远 |
| 光线一致 | 各格光源/色温与 scenes[] lighting 一致 |

> 批图版权威度低于逐镜首帧：它是"整场布局草图"，不替代首帧 5 项验收（production_guide §3）；审阅通过的价值 = 把站位/轴线类错误拦在最便宜的图层。
