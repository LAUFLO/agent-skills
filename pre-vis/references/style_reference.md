## 使用规则（2026-09-13 更新）

1. **选表**：阶段 0a-1 定风格时，从 §A/§B/§C 选**一个主风格**（+ §D 修饰词 ≤3 个）
2. **读块**：按路由表 read `素材库/风格提示词/` 对应条目，取整块（7 基础字段 + **S1~S9 参考槽位**：S1 人物外观 / S2 道具材质 / S3 运镜 / S4 拍摄技法 / S5 光色参数 / S6 VFX粒子 / S7 声音签名 / S8 帧率节奏 / S9 多人站位）
3. **回写**：整块写入 `series.json` 的 `style` / `style_keywords` / `style_negative` 字段；**并取 S1~S9 默认值写 `style_baseline`（8 项）**；风格定板参考图任务登记进阶段② 生成清单（Wave 0）；关键镜头 `overrides` 在 0a-3 登记 `style_moments[]`
4. **带入**：后续所有图/视频提示词的 ⑧ 位 = **完整风格块逐字抄入**（禁止回退成 4~6 关键词）；⑨ 位 = 风格负向 + 该镜头局部负向（双层风格锁，见 `素材库/风格提示词/README.md`）
5. **定板**：风格定板参考图（2~3 张无人物）= 项目级资产，E01 生成一次，E02~E04 引用不重出；批末风格漂移抽检基准 = 风格定板图
6. **混风格**：选"混风格"参考点（如 B-17 爱死机）时，`style_keywords` 必须锁死为该单元的具体子风格，禁止把"混合/随单元变"写进提示词
