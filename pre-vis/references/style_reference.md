## 使用规则

- agent 在阶段 0 确定 `style_keywords` 时，从 §A/§B/§C 中选择**一个主风格**
- 主风格 + §D 中的 2~3 个修饰词 = 该项目的 `style_keywords`
- 所有后续提示词自动带入 `style_keywords`，不逐镜修改
- 用户指定导演/工作室风格时（如"韦斯·安德森风格"），直接查 §A 对应行
- 选"混风格"参考点（如《爱，死亡与机器人》）为主风格时：`style_keywords` 必须锁死为该单元的具体子风格，禁止把"混合/随单元变"写进提示词
