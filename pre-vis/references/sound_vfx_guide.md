# 声音与VFX设计方法论

本文件定义声音设计（台词表演 / 环境音 / BGM 选曲）与 VFX 清单的决策规则与规格。
只定义**"声音该长什么样"**和**"哪里需要后期"**；分段/时长归 `video_prompt_guide.md` §2.1 / §2.10，执行细节归目标工具 skill。

## 1. 声音设计

### 1.1 台词表演规格（每行台词，写进 shot_NNN.md 的台词行）

**推导三步**：

```
Step 1 音色规格：取 series.json 的 voice_profiles（角色首单元定死，跨单元引用，不逐句重定）
        依据：角色 年龄 + personality + 当前 personality stage（多单元项目）
        例："男声，17岁，略哑偏低，音高偏低，语速慢"
Step 2 语气：`video_prompt_guide.md` §2.4 三问（潜台词 / 情绪 vs 台词 / 关系情境）→ 音量 / 音高 / 语速 / 停顿位置
Step 3 落位：台词在时间轴哪一段，前后各发生什么（`video_prompt_guide.md` §2.1 已有，不重新分段）
```

**写法**（写进视频提示词台词行）：

> "……没事。"（男声，略哑偏低）轻声，音高降 1 档，缓慢，尾音下沉；[停顿在"没事"前，半拍]

**规则**：
- 同一角色整集所有台词的**音色规格**必须与 `voice_profiles` 完全一致，只变语气不变音色
- 停顿位置/节奏按 `video_prompt_guide.md` §2.4 停顿位置决策表与节奏决策表推导，不随机
- **遮名可辨**：同场景多角色台词遮住角色名重读，认不出谁说的 → 重写该角色台词（用其口头禅/专属词汇/口癖，台词层的 feature_anchors）
- **潜文本三层**（McKee）：说出来的 / 未说出的（有意识隐藏）/ 说不出口的（压力下才暴露）——台词写表面层，但导演意图指向"未说层"；把潜文本直接写进文本 = "写在鼻子上"，重写
- **核心字眼三位置**：悬疑句（核心词在句尾，默认）/ 累积句（核心词在前，会话感）/ 平衡句（核心词在中）；同类设计连用 3 句 = 壁纸效应，混用
- **语言八法**（去干瘪对白）：实在不抽象 / 熟悉不陌生 / 短词不长词 / 直接不迂回 / 主动不被动 / 短句不长篇 / 有表现力不模仿 / 删多余词
- **角色专属三锚**：每个主要角色锁定 3~5 个专属词项（口头禅/专业词/句式习惯/文化符号），多角色场景写台词先查 `voice_profiles` + 该锚点（与遮名测试同源，台词层 feature_anchors）

### 1.2 环境音规格（每镜头，写进 shot_NNN.md「音频」小节）

**决策依据（逻辑同 `video_prompt_guide.md` §1.4 光源）**：

```
Step 1 物理约束：scene.time + location 里实际存在什么声
        （夜晚走廊 = 雨声 / 荧光灯嗡鸣 / 湿湿地面脚步；教室 = 挂钟 / 风铃）
Step 2 情绪匹配：环境音厚度与情绪强度**反比**——
        平静场景：环境床厚（雨中景）；对白/高潮镜：环境渐弱，只留关键音（机芯滴答/心跳）
Step 3 一致性：同场景相邻镜头环境床相同，不许雨声中途无故停
```

**写法**：

```
> 环境音：窗外细雨（中），远处雷鸣（轻），荧光灯嗡鸣（很轻）
> （高潮镜）环境音：雨渐弱（-12dB），只留怀表机芯滴答（近）
```

### 1.3 BGM 选曲规格（按幕，写进 sound_vfx.md）

**推导链**：

```
act.emotional_arc → 音乐情绪曲线
→ 风格 / 配器 / 调性 / BPM（查下表）
→ cue 点：何时进、何时让位（对白镜头/情绪转折点）、何时停
→ 素材库搜索关键词（用户手动选曲，本 skill 不生成音乐）
```

**风格参考表**：

| 情绪曲线 | 风格/配器 | 调性 | BPM |
|---------|----------|------|-----|
| 平静 → 紧张 | ambient + 钢琴 | 小调 | 60~80 |
| 紧张 → 高潮 | ambient + 弦乐 / 低频 drone | 小调 | 80~110 |
| 希望 / 温暖 | 木吉他 / 钢琴 | 大调 | 70~100 |
| 孤独 / 余韵 | 独奏钢琴 / 音乐盒 | 小调或大调 | 50~70 |

**cue 点规则**：
- BGM 从本幕建立镜头进（该幕 shot_001 或第一个有情绪的镜头）
- **让位规则**：对白镜头/情绪转折点压低 -12dB 以下（参考起点值，按素材实际响度 ±3dB 调），不与台词抢
- 幕内高潮允许一次"停顿"（静默 1~2s 再进）
- 一幕 1~2 个 cue；让位点必须写明

**素材库**：Pixabay Music / YouTube Audio Library / Free Music Archive（免费可商用，确认 license）
搜索关键词示例：`tense ambient piano minor 75bpm restrained`

> BGM 不走视频模型生成：cue 点必须对齐情绪转折点，模型生成音乐不可控、不可复现。

### SFX（音效）来源（与 BGM 同源，不生成）

- 音效由用户从免版权音效库选（同一批素材库），`sound_vfx.md` 出 **SFX 清单**：素材描述 + 参考点（覆盖哪个拼接接缝）+ 时长
- 分段拼接镜头的接缝必须有连续 SFX 床覆盖（验收第 4 项）；pre-vis 不生成音效

## 2. VFX 清单

**原则：所有元素一律先写进提示词**，写精细即可。生成后验收检查；不达标时用户选"重新 prompt"或后期合成（可参考"后期 fallback"列，或现场处理）。不预判模型能力，不做风险分级。

### 2.1 元素描写精细标准（四维度）

镜头中任何要体现的元素（粒子 / 光效 / 烟 / 水面 / 布料等），按以下结构描述：

```
形态：它长什么样（雨丝细密 / 雪花棉絮 / 烟薄而卷 / 光斑圆形）
数量：多少（密集，画面 100+ 颗粒 / 稀疏）
方向：往哪动（斜向右下 30°，带风偏）
次级效果：它影响了什么（肩头溅水雾 / 地面积水反射冷蓝光 / 前景动态模糊）
```

简单元素（漏光/薄烟）写 1~2 维即可；复杂元素（大雨量/粒子/烟火）四维度写全。

> **经验提示（非规则）**：画面文字/logo、水面精确倒影这类元素历史上是模型弱项，生成后优先检查；不达标走该行的后期 fallback。
> **强度随情绪**：建立镜 VFX 最少，高潮镜最大。

### 2.2 按镜头 VFX 行

| 镜头 | 元素 | prompt 写法（§2.1 四维度）| 后期 fallback（可选）|
|------|------|---------------------------|----------------------|
| shot_012 | 怀表漏光 | "暖黄漏光从右侧，8000K" | 剪映光效，透明度 40% |
| shot_012 | 指针光环 | 光斑圆形，密集，从表盘向外，轻微闪烁 | 后期叠加，光晕素材 3~6s |

> "后期 fallback"列是**可选的保险线**：规划时写一行（30 秒），生成失败时直接执行不卡壳；不写也行，失败时现场用剪映/AE 处理。本表规划完即定稿，无回写动作。
