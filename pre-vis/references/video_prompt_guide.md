## 1. 镜头首帧提示词

**核心原则**：首帧描述的是**动作开始前的瞬间**，不是视频结束状态。

### 镜头语言速查（写"镜头"字段前必查）

**焦距决策表**（9 要素② 按需写明，默认省略 = 中性 50mm）：

| 焦距 | 画面效果 | 叙事用途 | 何时写 |
|------|---------|---------|------|
| 广角 24~35mm | 透视夸张、空间扩展、边缘微变形 | 空间压迫感、主观沉浸、动感 | 需要强调环境压迫/失衡时写 |
| 长焦 85mm+ | 背景压缩拉近、主体与环境隔离 | 疏离感、被窥视感、孤独 | 需要把角色与环境隔离时写 |

景深决策表见 9 要素示例下方（⑥ 引用）。

### 1.0 镜头语言参考（撰写提示词前必查）

**镜头规格**（每条提示词的"镜头"字段写全：角度/景别/运镜三要素 + 可选焦距/景深；焦距/景深查上方"镜头语言速查"与下方 §1.1 决策表，默认省略）：
```
[角度][景别][运镜]
如："平视，中景，固定" 或 "仰拍，近景，缓慢推近"
```

#### 拍摄角度（9种，分三组）

**高度角度**：

| 角度 | 提示词写法 | 情绪含义 | 适用场景 |
|------|----------|---------|---------|
| 平视 (eye-level) | "镜头与人物视线齐平，平视角度" | 冷静、客观、平等 | 对话、叙事、基础镜头（最常用）|
| 俯拍 (high-angle) | "高角度俯拍，从上方约45度向下拍摄" | 孤独、渺小、无助、被审视 | 暗黑故事、命运感、弱者处境 |
| 仰拍 (low-angle) | "低角度仰拍，从人物脚部向上拍摄" | 威严、强大、英雄感 | 人物登场、反派气场、英雄时刻 |

**人物朝向**：

| 朝向 | 提示词写法 | 情绪含义 | 适用场景 |
|------|----------|---------|---------|
| 正面 (front) | "正面拍摄，镜头正对人物面部" | 展现情绪、内心、直接沟通 | 对白、情绪特写、内心戏 |
| 侧面 (profile) | "侧面拍摄，镜头与面部约90度，单侧轮廓" | 沉思、观望、冷漠、疏离 | 内心戏、旁观、冷漠关系 |
| 背面 (back) | "背面拍摄，镜头在人物正后方，面部不可见" | 悬念、代入、孤独、未知 | 开场、离别、探索场景 |

**特殊视角**：

| 视角 | 提示词写法 | 情绪含义 | 适用场景 |
|------|----------|---------|---------|
| 鸟瞰 (bird's-eye) | "鸟瞰视角，模拟高空俯冲，上帝视角" | 史诗感、宿命感、全景 | 大场景、战争、城市、命运 |
| 虫视 (worm's-eye) | "虫视视角，贴地面向上拍摄，蚂蚁视角" | 视觉冲击、宏伟、新奇 | 建筑、巨人、震撼场景 |
| 荷兰角 (Dutch angle) | "荷兰角，画面水平线倾斜约15度" | 失衡、紧张、不安、压抑 | 动作片、惊悚、心理异常 |

#### 景别（6种）

| 景别 | 提示词写法 | 适用场景 |
|------|----------|---------|
| 大远景 | "大远景，人物占画面<10%，环境为主体" | 环境建立、史诗开场 |
| 远景 | "远景，人物占画面<20%" | 场景交代、人物位置关系 |
| 中景 | "中景，人物腰部以上入画" | 对话、动作、叙事基础（最常用）|
| 近景 | "近景，人物胸部以上入画" | 情绪表达、对白 |
| 特写 | "特写，仅面部/眼睛/手部入画" | 微表情、关键道具、情绪高潮 |
| 大特写 | "大特写，仅眼睛/嘴唇/单一细节入画" | 情绪顶点、悬念、关键瞬间 |

#### 组合规则

- 角度 + 景别 + 运镜三者**自由组合**
- 荷兰角只适合**近景/特写**（大远景倾斜无意义）
- 鸟瞰/虫视通常配**远景/大远景**
- 同一镜头内角度/景别**保持稳定**，除非在时间轴中明确描述变化

#### 选择顺序（写"镜头"字段时按此顺序，每项都是"选出来的"不是"拍脑袋填的"）

1. 先查 `shot_purpose` → 定典型景别（§1.2 表格）
2. 再查 `emotional_register`（§1.3 推导结果）→ 微调角度：
   平静/中性 = 平视；宿命/渺小/弱势 = 俯拍；英雄/反派登场 = 仰拍；不安/失衡 = 荷兰角；孤独/内心 = 侧面或背面
3. 运镜按文末"运镜决策规则"单独决定：情绪无变化 = 固定（默认，干扰最小）
4. 焦距/景深按"镜头语言速查"与 §1.1 决策表定，默认省略（= 50mm 中性 / 不写景深）

### 1.1 固定提示词组装顺序（9 要素，所有镜头统一）

> 固定顺序让 100 个镜头的提示词可审计、可对比、不遗漏。

```
① 镜头规格：[角度 + 景别]（运镜不进首帧——静图无运镜，运镜只写在视频时间轴段）
② 画幅/镜头：[16:9 / 9:16 / 2.39:1]，[焦距（省略 = 50mm 中性；广角/长焦查"镜头语言速查"焦距决策表）]
③ 光源：[具体位置 + 色温数值 + 明暗比]
④ 色板/色调：[主色调 + 辅色调]
⑤ 构图：[主体位置 + 负空间]
⑥ 氛围层+景深：[前景 / 中景 / 背景 各有什么] + [景深（浅/深/拉焦，§1.1 景深决策表）]
⑦ 情绪基调：[该镜头的 emotional_register]
⑧ 风格：[全集 style_keywords = 完整风格块逐字抄入，非 4~6 关键词串]
⑨ 负向约束：[风格负向（series.json style_negative）+ 该镜头局部 negative_prompt]（焦距/景深未写 = 中性）
```

**示例**（完整 9 要素）：
> ① 平视，中景（运镜"固定"写在视频提示词侧）
> ② 16:9，35mm
> ③ 冷蓝色荧光灯从天花板上方照射，8000K，暗:亮 70:30
> ④ 主色冷蓝，辅色暖黄（远处光斑）
> ⑤ 主体居画面中偏左，右侧留 1/3 负空间（孤独感）
> ⑥ 氛围层+景深：前景：雨水滴落的窗户玻璃；中景：林晨；背景：走廊深处暖黄光（浅景深，背景虚化）
> ⑦ 压抑的孤独
> ⑧ 日系2D赛璐珞动画风格，柔和光影，16:9电影画幅
> ⑨ 无侧面机位，无夸张表演，无AI塑料感，无字幕水印

**S 槽位路由（双层风格锁，2026-09-13）**：9 要素取值查 `素材库/风格提示词/` 对应风格块的 S1~S9（"阶段→槽位速查表"）：① 镜头规格 = **S3 运镜**；② 画幅/焦距 = **S4 拍摄技法**；③ 光源 = **S5 光色参数**；④ 色板 = **S5**；⑤ 构图 = **S9 多人站位**（单人 = S3 构图习惯）；⑥ 氛围层 = **S2 道具材质 + S6 VFX/粒子**；⑦ 情绪 = `emotional_register`；⑧ = 完整风格块（逐字抄入）；⑨ = 风格负向 + 镜头局部负向。命中 `style_moments[]` 的镜头 = 基线 + moment 覆盖项（**覆盖仅限 L2/L3 项，L1 全片硬锁不可动**），其余 = 纯基线 + L3 槽内微调，**禁表外发明**。

**负空间情绪判据**（⑤ 构图"负空间"部分查用）：
- 大量留白（角色占画面 <1/3）= 孤独 / 渺小 / 压力
- 角色望向负空间 = 望向未知 / 犹豫
- 角色紧贴画面边缘 = 局促 / 不安

**景深决策表**（⑥ 氛围层+景深"景深"部分查用）：

| 选项 | 效果 | 判据 |
|------|------|------|
| 浅景深 | 主体清晰、前后虚化，注意力锁定 | 对白/特写默认 |
| 深景深 | 前中背景均清晰，多层信息共存 | 环境压迫/悬疑/多层调度 |
| 拉焦 | 镜头内焦点从一层移到另一层 = 注意力转移 | 写入 §2.1 时间轴段 |

### 1.2 镜头目的（Shot Purpose）

每个镜头有**一个**明确目的，写进 `shot_purpose` 字段：

| 目的 | 说明 | 典型景别 | 推荐镜语套餐（默认值，可被情绪推导覆盖）|
|------|------|---------|------|
| `establish` | 观众第一次看到这个场景/地点 | 大远景/远景 | 平视 + 固定/升降 + 广角或中性 + 深景深，6~10s |
| `reveal` | 新道具/新角色/新线索入画 | 中景/近景 | 平视 + 缓推 + 中性/长焦 + 浅景深，6~10s |
| `action` | 某个具体动作发生 | 中景/近景 | 广角 + 跟/移，中景深，4~8s |
| `reaction` | 角色对某事件的反应 | 近景/特写 | 中性 + 固定 + 近，浅景深，4~6s |
| `transition` | 两个场景/时间段之间过渡 | 任意 | 见"转场速查" |
| `pov` | 主观镜头：观众透过角色视线看世界（写"机位 = 角色A 眼位，看向 B"）| 近景（看向对象）| 平视 + 固定/跟，中性，4~8s |
| `insert` | 对白/动作中插入关键道具/物件特写，打断节奏 | 大特写 | 中性/俯拍 + 固定，浅景深，4s；置于台词前后 |
| `twoshot` | 两人同框建立空间关系（对话戏标准起手）| 全景/中景 | 平视 + 固定，中景深，6~10s；站位按 §2.8 关系基线 |
| `empty_shot` | 空镜：无人物，情绪呼吸/时间过渡 | 远景/大远景 | 中性 + 固定/缓推，深景深，6~15s；首帧可直接复用场景图（assets_prompt.md），不单独生成 |

**转场速查**（shot_purpose = transition / empty_shot 时查用）：

| 转场 | 执行方式 | AI 视频注意 |
|------|---------|-----------|
| 物件转场 | 前镜落点在物件/动作，后镜从该物件/动作在新空间起 | 相邻两镜文字写明同一物件 |
| 视线转场 | 前镜结尾视线 = 后镜开头目标 | 可配合 prev_shot_ref |
| 空镜呼吸 | 插入纯场景镜头（无人物）| empty_shot：首帧 = 场景参考图，不重新生成 |
| 日夜跳切 | 场景光线变化过时间 | 相邻两镜均无人物，仅 scenes[] lighting 变化 |
| 匹配转场 | 两镜构图/主体同构 | 前一镜尾帧与后一镜首帧同构（两处文字写明）|

**原则**：一个镜头只做一件事。如果 `shot_purpose` 写不出单一目的，说明该镜头需要拆分。

### 1.3 情绪基调推导规则（`emotional_register` 的确定）

`emotional_register` 不得拍脑袋填写，按三步推导：

```
Step 1 承接：前一镜头的情绪落点 → 本镜头的情绪起点
        （同场景相邻镜头必做；启用 prev_shot_ref 时承接更强）
Step 2 事件：本镜头内「动作」/「台词」造成的情绪转折点
        （写法：「状态A → 状态B」；转折多于 1 个时，在 §2.1 时间轴拆多段）
Step 3 性格过滤：weakness 被触发 → 加「克制/压抑」修饰；
        高潮位（act 转折/高潮节点）→ 允许「释放」；内向角色默认压抑外放
约束：不得与本镜头所属 act 的 emotional_arc 冲突
        （act.emotional_arc = 该 act 所有镜头情绪走势的摘要；镜头是细节，幕是主线）
```

**推导链示例**（shot_002）：
- 前镜头（shot_001）情绪落点：平静（林晨雨夜回家路上）
- 本镜头事件：捡到怀表，发现指针倒转（动作）
- 性格过滤：林晨 weakness =「害怕失去」+ 内向 → 震惊被压抑
- 推导结果：`emotional_register = "困惑 → 震惊（压抑）"`
- 校验：act_1.emotional_arc =「平静 → 好奇 → 紧张」✅ 不冲突

### 1.4 光源与色板决策规则（③ 光源 / ④ 色板 / `color_script` 的确定）

光源不是装饰，每个选择必须能回答"为什么是这道光"。四步决策：

```
Step 1 物理约束：scene.time + scene.location → 该时空物理上存在什么光源
        （黎明 = 低角度暖光；室内夜 = 台灯/荧光灯/霓虹；户外夜 = 月光/路灯）
Step 2 情绪匹配：当前情绪基调（§1.3 推导结果）→ 色温 + 明暗比
        关系维度：画面角色的关系状态（查 `relationships[]` 当前单元 state）：亲密/和解戏偏暖，
        对抗/疏离戏偏冷；B 故事场景（scenes[].line = B）全单元统一色偏（视觉区分支线）
Step 3 一致性：光源类型必须与 scene.lighting 字段一致（场景级基线光）；
        镜头级只允许调明暗比/角度，不允许换光源类型
        （荧光灯走廊的场景，不许突然写成月光，除非镜头明确是"走到窗边"）
Step 4 弧线外化（多单元项目）：光影随角色弧线推进——
        同一场景在系列首尾两单元，明暗基调应有可见变化
        （首单元冷蓝压抑 → 尾单元暖黄开放 = 角色获得自由）
```

**色温情绪映射表（Step 2 查用）**：

| 色温/光型 | 情绪映射 | 典型用途 |
|---------|---------|---------|
| 8000K+ 冷蓝 | 孤独、冷峻、夜晚、威胁 | 雨夜、独处、发现真相前 |
| 3200K 暖黄 | 安全、温暖、记忆、怀旧 | 家中、闪回、和解后 |
| 高对比单色（橙红/蓝）| 宿命、对抗、戏剧性 | 正邪对峙、高潮 |
| 霓虹（品红+青）| 虚幻、欲望、未来感 | 都市夜戏、科幻设定 |

> 负向校验：写完后自问——"如果这个光源换成另一种，剧情还成立吗？"若答案是不影响，说明光源没承载叙事，需要重查 Step 2/4。

| 有 `prev_shot_ref`，无角色参考图 | @1=`frames/{prev_shot_id}_last.png` @2=场景图 |
| 无 `prev_shot_ref` | 按上表常规分配 |

> 工具 @N 上限不足时：**砍道具图，保留角色（身体+头部卡）+前一帧**；仍超出则砍场景图，场景写进提示词文字；**头部卡不砍**（面部主锚，与尾帧同级不可降级）。

> 无尾帧的镜头 @N 序号自 @4 起顺移：@4 = 第二角色图，@5 = 焦点道具图（尾帧槽位不预留）；槽位优先级（含头部卡 `c01_head*` 排场景图前、不可降级）见主文"@N 槽位优先级"。

**注意**：@N 数量不得超过目标生成工具支持的参考图上限（见 §3）。

## 2. 视频动作提示词（所有镜头统一格式）

### 核心规则

| 规则 | 说明 |
|------|------|
| 写动态过程 | 描述"镜头内发生了什么"，**不重复**首帧的静态画面 |
| 主体动作 | 角色动作链，写清楚起始/过程/落点 |
| 运镜 | 明确写一种运镜，不写"多角度" |
| 节奏 | 快/慢/渐强/渐弱，对应情绪 |
| 情绪 | 用词具体（"强行压住的冷硬"而非"冷"）|

**❌ 常见错误**：写成静态画面描述。"一个男生站在走廊里，拿着怀表"是首帧内容，不是视频动作。

**S 槽位路由（视频动作侧，2026-09-13）**：运镜段 = **S3 运镜**（基线 camera + moments 覆盖）；特效段 = **S6 VFX/粒子**（该风格特效语法：手绘 FX / 粒子模拟 / 网点辉光 / 实拍烟）；表演段 = **S1 人物外观**（表情夸张度档）；节奏/段数 = **S8 帧率/节奏**（剪辑节奏 + 慢镜约定）；③.5 BGM/SFX = **S7 声音签名**（cue 密度对照 S8）

### 2.1 时间轴分段（所有镜头统一使用）

每个视频提示词**必须**按时间段拆分。

**段数由镜头内"情绪/动作转折点数量"决定，不是按时长机械分配**：

| 判断依据 | 说明 |
|---------|------|
| 情绪变化次数 | 每次明显情绪转折（平静→紧张、愤怒→心碎）= 一个新段 |
| 台词断句位置 | 每句台词前后 = 自然分段点 |
| 景别/运镜切换 | 每次切近/拉远 = 考虑分段 |
| 动作落点 | 每个独立动作完成（"抬手"→"停住"）= 一个新段 |

**时长参考**（仅作上限参考，不作下限）：

| 镜头时长 | 常见段数 | 上限 |
|---------|---------|------|
| 4s | 1~3 段 | 3 |
| 6~8s | 2~4 段 | 5 |
| 10~15s | 3~6+ 段 | 不限制，以转折点数为准 |

**时长决策公式**（在参考范围内选具体值）：

```
时长 ≈ 段数 × 2~4s/段 + 情绪强调修正
- 情绪顶点单镜（act 转折点 / emotional_arc 顶点，每段限 1~2 个）：+1~2s 留白
- 纯建立 / 过渡镜：-1s
- 定完后对 §2.10 台词计时校验：字数 ÷ 2.5 ≤ 时长（秒），超出则拆镜头
```

**镜长节奏（段落级基准，plot_map 核对）**：
- 平静/建立段：镜头时长基准 8~12s；发展段：6~8s；高张力/高潮段：压到 4~6s（节奏加快）
- 上述"+1~2s 留白"只适用于"情绪顶点单镜"，段内其余镜头按基准执行
- plot_map.md 每段写一行"镜长节奏"（见 skill.md 阶段 ① plot_map 内容）

**核心原则：宁多勿少，每个独立的情绪/动作转折都值得单独成段，不按时长强行合并。**

```
[时间段A：0~Xs]
- 动作：[主体做了什么，含起始/过程/落点]
- 情绪：[当前情绪状态，用词具体]
- 镜头：[角度+景别+运镜，如"平视，中景，固定"或"仰拍，近景，缓慢推近"]

[时间段B：X~Ys]
- 动作：...
- 情绪：...
- 镜头：...

【最后一段必须写清楚落点：动作结束时的姿态/表情/镜头状态】
```

**4s 简单镜头示例**（2 段）：
> [0~2s] 主角从画面左侧入画，步伐平稳，面向画面右侧，中景固定
> [2~4s] 主角停步，缓慢转身面向镜头，表情平静，落在画面中心

**15s 复杂表演镜头示例**（6 段，以情绪转折为准）：
> [0~5.5s]  抬剑，压抑追问（"为什么"×3 情绪递进），正面近景缓推
> [5.5~9s]  切近面部，心碎（无台词），情绪退潮，特写
> [9~12s]   想起血仇，重新握剑，回到近景，情绪从心碎转决心
> [12~13.2s] 第二句台词（觉悟），低声，特写
> [13.2~14.4s] 完整起手式（5个动作步骤），近景
> [14.4~15s]  一剑刺镜头，短快狠，定格

**原则**：
- 每段有**一个情绪转折点**或**一个动作落点**，不堆叠多个独立动作在同一段
- 时间段之间镜头变化要**自然**（切近≠换机位，写明"只是景别变化"）
- 空镜头/纯场景过渡（无角色动作）可以只写 1 段

### 2.2 动作描写（有肢体动作的镜头加入）

**核心原则**：复杂动作拆分为**步骤**，每步独立描述，不合并。简单动作（1~2步）直接写在时间轴段内。

#### 动作五要素（每个步骤写全）

| 要素 | 说明 | 示例 |
|------|------|------|
| 部位 | 具体到哪个身体部位 | "五指"而非"手"，"手肘"而非"手臂" |
| 方向 | 动作空间方向 | "向上微抬"、"完整向后拉开"、"向前压" |
| 速度 | 快/慢/克制 | "不要快，必须看得清"、"骤然发力" |
| 力度 | 轻/重/爆发 | "轻微"、"明显收紧"、"完全静止" |
| 物理感 | 有重量/有轨迹 | "剑身必须有清楚的后撤轨迹" |

#### 动作链写法（≥3 步骤的动作必用）

```
第一步·[动作名]：[部位 + 方向 + 速度 + 力度 + 物理感]
第二步·[动作名]：[部位 + 方向 + 速度 + 力度 + 物理感]
...
【落点】动作完成后的最终姿态/表情/镜头状态
```

**示例**（完整起手式，5步）：
> 第一步·握紧：五指再次收紧剑柄，指节绷起，手腕稳定，剑尖完全静止
> 第二步·抬剑：剑明确向上微抬一段，动作不快，必须看得清
> 第三步·后拉蓄力：握剑手和剑身完整向后拉开，有清楚后撤轨迹，不闪而过
> 第四步·肩肘回收：手肘明显后收，持剑侧肩膀同步后带，双眼仍锁定镜头
> 第五步·蓄势：上半身重新前压，重心调整，极短一瞬停顿，进入爆发状态
> 【落点】剑完全蓄好，面部冷静，正面近景，观众明确意识到下一秒出剑

#### 动作与情绪关联（动作是内心状态的外化）

| 内心状态 | 动作外化写法 |
|---------|------------|
| 犹豫/想放弃 | 握力松动，武器缓慢下沉（不是放下）|
| 决心/接受 | 五指重新收紧，指节明显，武器完全静止 |
| 愤怒/压抑 | 后槽牙咬住，下颌绷紧，握持手微颤 |
| 爆发 | 骤然发力，短、快、狠、直接，无多余动作 |
| 平静/克制 | 呼吸浅，动作慢，力度轻 |

#### 速度/节奏词库

| 节奏 | 提示词写法 | 适用场景 |
|------|----------|---------|
| 缓慢/克制 | "动作不要快，必须看得清"、"一点点进入画面" | 情绪酝酿、蓄力 |
| 渐强 | "逐渐抬高"、"越来越明显" | 情绪升级 |
| 突然/爆发 | "骤然发力"、"短、快、狠、直接" | 高潮、出招 |
| 停顿 | "极短、极有张力的一瞬停顿" | 情绪转折 |
| 渐弱/停止 | "颤抖逐渐减弱，最终完全停止" | 收束、决心 |

### 2.3 微表情层次（面部特写镜头加入）

**表情决策流程（写面部特写前必须执行）**：

```
Step 1 叙事触发：这个 shot 发生什么事？对角色意味着什么？（来自 script.json 的「动作」+「shot_purpose」）
Step 2 性格读取：读本单元 script.json 角色 personality + temperament + weakness；
        画面有对手戏角色时，加查 `series.json` `relationships[]` 该角色对当前单元 state——
        同一情绪对不同关系对象表现不同（对敌人藏怒 vs 对至亲忍怒，动作/眼神落点不同）
              （多单元项目下 personality 来自 series.json character_arcs[].personality_progression 该单元 stage）
Step 3 基调锁定：shot 的 emotional_register 字段（如"压抑的孤独"、"克制的愤怒"）
Step 4 性格过滤：查下方对照表，同一情绪不同性格的外在表现差异明显，选对应列
Step 5 强度判断：事件对该角色冲击 1~5 分；weakness 被触发 → +1；决定用"察觉"还是"释放"
Step 6 选词写入：按下方词汇库，选 Step 4/5 对应词，顺序"眉眼→嘴唇→下颌→鼻翼→喉部→身体"
```

**性格过滤对照表（Step 4 查用）**：

| 情绪 | 内向/敏感 | 外向/爆发 | 冷静/克制 | 傲娇/嘴硬 |
|------|----------|----------|----------|----------|
| 震惊 | 眼睑微张，眼神失焦，身体僵住，嘴唇微张 | 身体前倾，嘴大张，声音上扬，后退一步 | 眼睑压低，眼神锁定，下颌绷紧，一动不动 | 嘴角一抖，眼神先躲开再锁定，脸微红 |
| 悲伤 | 眼眶泛湿，眼睑压低，呼吸变浅，肩膀内收 | 皱眉，泪落，肩膀颤抖，声音哽咽 | 下颌绷紧，喉部一次吞咽，眼眶泛湿不落泪 | 嘴唇抿紧，眼神先看向别处，再偷看一眼 |
| 愤怒 | 眉间收紧，嘴唇闭紧，指节绷起，沉默 | 身体前倾，拳头握紧，声音抬高 | 眼睑压低，眼神锁定，后槽牙咬住，一句极短的话 | 嘴角下撇，眼神犀利，"哼"一声 |
| 喜悦 | 嘴角微动，眼神软化，肩膀放松 | 忍不住笑，身体前倾，声音上扬 | 眉心上抬，一次克制的笑，点头 | 眼神躲开，耳尖泛红，小声"才不是" |

> 对照表为方向参考；实际写提示词时以该角色具体 `personality` 描述为准，结合 Step 5 强度调整，不必全部写入。

**按以下顺序逐项描述，不跳项**：

```
眉眼 → 嘴唇 → 下颌 → 鼻翼 → 喉部 → 握持/身体力度
```

**微表情词汇库**（按需选用，不是每项都要写）：

| 部位 | 可用描述 |
|------|---------|
| 眉眼 | 眉间收紧 / 眉心上抬 / 眼睑压低 / 眼睑微张 / 眼神失焦 / 眼神锁定 / 眼眶泛湿 / 眼角微颤 |
| 嘴唇 | 嘴唇闭紧 / 下唇轻颤 / 嘴唇微张 / 嘴角细微抖动 / 吞咽 / 咬住下唇 |
| 下颌 | 下颌绷紧 / 后槽牙咬住 / 下巴微抬 / 下巴内收 |
| 鼻翼 | 鼻翼随呼吸张合 / 鼻翼轻动（吸冷空气）|
| 喉部 | 喉部一次克制吞咽 / 喉结微动 |
| 握持/身体 | 指节绷起 / 握力收紧 / 肩微耸 / 重心前移 |

**写法示例**：
> 眉间收紧，眼睑压低，下颌绷紧，后槽牙咬住，嘴唇闭紧，
> 鼻翼随压抑的呼吸轻微张合，呼吸很浅，
> 喉部出现一次克制但清楚的吞咽，眼眶泛湿但绝不落泪

### 2.4 台词表演（有对白的镜头加入）

**台词决策规则（写之前必须回答三问）**：

```
Q1 潜台词：这句话"真正在说"什么？
   表面义 = 字面内容；潜台词 = 角色真正想说/想藏的东西
   两者差距 = 表演空间：差距大 → 多停顿/音量降/眼神移开
   表面 = 潜台词（陈述事实、传达信息）→ 正常节奏，不加额外表演
Q2 情绪 vs 台词：
   情绪 > 台词 → 压抑型：低声/哽咽/停顿/眼神不对焦
   台词 > 情绪 → 表达型：平稳/清晰/直视对方
Q3 关系 + 情境：与对方的地位差（下/平/上）、公开 or 私密、有无第三者在场（地位差/关系状态查 `series.json` `relationships[]` 对应角色对在当前单元的 state，不现场猜）
   → 决定"能不能说出口 / 必须压住说"
```

**停顿位置决策表**：

| 停顿位置 | 作用 | 示例 |
|---------|------|------|
| 最重要的字**之前** | 强调（那个字最难说出口）| "其实……我从来没有[长停顿]后悔过。"|
| 两句台词之间**长停顿** | 内心斗争/决定要不要继续说 | 情绪转折点必用 |
| 台词说完**短停顿** | 余情未了，情绪没落地 | 接下一句或接沉默 |
| 无停顿连说 | 情绪失控，话是唯一的出口 | 高潮爆发 |

**节奏决策表**：

| 节奏 | 何时用 |
|------|------|
| 前快短、后放慢 | 情绪上升，从冲动到克制 |
| 整体慢、个别字突然挤出 | 压抑型角色，反差即爆发点 |
| 节奏乱、断在半句重来 | 情绪崩溃、说不下去 |
| 平稳清晰 | 客观叙述、信息传达 |

**不是写"说了什么"，而是写"怎么说"**：

```
"台词原文"

断句：[在哪个字后停顿，停顿多长]
每句情绪：[压低 / 轻声 / 逐渐升高 / 压不住的追问 / 强行挤出]
台词之间：[沉默 / 呼吸 / 眼神变化 / 嘴唇微颤 / 握持力度变化]
真正的情绪爆发在台词之间，不在台词本身
```

**写法示例**：
> "为什么……" 声音很低，像从牙缝和胸口之间强行挤出，压抑、带恨。
> 停顿，她盯着镜头，呼吸更重了一点。
> "偏偏是你……" 声音反而变轻，愤怒下面第一次露出痛，眉心稍微松动，眼神短暂失神。
> "为什么？" 情绪重新往上翻，声音稍高，压不住的追问，眉间再次收紧。

### 2.5 负向约束（每个视频提示词末尾必加）

【禁止】
- 换机位 / 突然跳切（除非时间轴中已明确描述该变化）
- 夸张表演：豪哭 / 歇斯底里 / 大幅摇头 / 夸张皱脸 / 偶像剧式哭腔

```

**原则**：写**具体禁止项**，不写"不要奇怪"这类模糊表述。

### 2.7 物理真实感（场景有自然元素的镜头加入）

【物理真实感】

- [雪/雨/灰尘] 自然落在 [睫毛/肩膀/武器/皮肤]
- 呼吸带 [白气/热气]（根据环境温度）

```

### 2.8 屏幕方向 / 180度轴线（多镜头场景必查）

**规则**：同场景中，角色的移动方向在所有镜头中保持一致。
**空间布局（多角色场景）**：关系状态决定站位基线——查 `relationships[]` 当前单元 state：对抗/敌对 = 对坐/对立站位，亲密/同盟 = 同侧/肩并肩，地位差（下/上）= 位置高低差；关系演变（如背叛发生）后，后续镜头的站位基线随之切换。

| 情况 | 结果 |
|------|------|
| 角色从左往右走，所有镜头保持 | ✅ 正确 |
| 角色从左往右走，某镜头突然从右往左 | ❌ 违反 180度轴线，剪辑时空间混乱 |

**`screen_direction` 字段取值**：

| 值 | 说明 |
|----|------|
| `left_to_right` | 角色主要移动方向：画面左→右 |
| `right_to_left` | 角色主要移动方向：画面右→左 |
| `static` | 角色基本不动（对白/静止镜头）|

**agent 自检规则**：同场景相邻镜头的 `screen_direction` 必须一致；不一致时在 `script.json` 中标注警告，用户确认后才可接受。

**初始方向决策**（场景第一个移动镜头先定这个，后续镜头跟随）：

```
"前进方向"规则：
- 角色目标方向（叙事要前进的方向）= 默认 left_to_right
- 受挫/反击/撤退/被推走 = right_to_left
- 纯静止/对白场景 = static
> 故意反转制造"错位感"仅当叙事意图明确时允许（如角色受挫后前进方向整体反转为右→左），
> 且反转必须用一个独立镜头展示，不许在镜头间悄悄换。
```

---

### 2.9 一镜一动作 + 一镜一运镜（防超负荷）

**核心规则**：每个镜头只包含**一个主要动作 + 一个主要运镜**。

| 情况 | 处理 |
|------|------|
| 一个镜头要"转身+开枪+后退+倒地" | 拆成 4 个镜头 |
| 一个镜头要"推近+横摇+升降" | 选一个主运镜，其余砍掉 |
| 一个镜头要"说台词+做动作+表情变化" | 可以（台词不算动作），但表情变化写进微表情层 |

> 行业共识："If the card calls for an orbit, hand interaction, smoke transformation, expression change, and typography reveal, split it into several shots."

---

### 2.10 台词计时规则

**速度基准**：中文旁白/对白约 **2.5 字/秒**。

| 镜头时长 | 最多台词字数 | 超出处理 |
|---------|----------|---------|
| 4s | 10 字 | 拆成两个镜头 |
| 8s | 20 字 | 拆成两个镜头 |
| 12s | 30 字 | 考虑加快节奏或拆镜头 |
| 15s | 37 字 | 接近上限，检查是否需拆 |

**校验**：agent 拆剧本时自动检查 `narration`/`dialogue` 字数 ÷ 2.5 ≤ `duration_seconds`，超出则标注警告。

### 运镜词汇表

**运镜决策规则**（选之前必须能回答"为什么这个运镜"）：

```
运镜 = 情绪/叙事的物理外化，不是为了"好看"
- 无情绪变化、纯信息传达        → 固定
- 注意力/情绪逐渐上升（进入角色内心）→ 缓推
- 情绪释放/退潮、角色与环境对比（孤独）→ 拉
- 角色在移动、观众跟随/追寻       → 跟
- 跟随视线、扫视环境、空间过渡     → 横摇
- 局势不稳（混乱/追逐/纪实感）    → 手持
- 情绪抬升/大场景揭示            → 升降
- 大场景、速度感、宿命感        → 无人机
```

| 运镜 | 决策依据（何时用）|
|------|---------|
| 固定 / locked | 对白、停顿、悬念、纯信息传达（默认选择，干扰最小）|
| 推 / dolly in | 强调、聚焦，注意力/情绪逐渐上升 |
| 拉 / dolly out | 揭示、孤立感，情绪释放/退潮 |
| 横摇 / pan | 跟随移动、扫视、空间过渡 |
| 跟 / tracking | 跟随人物走动，观众参与/追寻 |
| 手持 / handheld | 紧张、纪实感、混乱局势 |
| 升降 / crane | 全景揭示、情绪抬升 |
| 无人机 / aerial | 大场景、速度感 |

> §2.9"一镜一运镜"约束：只选**一个**最贴合本镜头情绪变化的运镜；拿不准就用固定。

### 2.11 镜间关系规则（agent 拆剧本时逐场景自查，相邻镜头对照）

| 规则 | 判据 | 违反处理 |
|------|------|---------|
| 30°/景别差 | 同一主体两个相邻镜头：角度差 ≥30° **或** 景别差 ≥ 一级；两者都不满足 = 跳切 | 调整下一镜角度/景别，或在中间插入 twoshot / insert |
| 景别序列 | 不连续两镜同景别；"切近"（逐级推近）= 情绪升级，"切远" = 情绪退潮 | 重排镜头或改景别 |
| 动作剪辑 | 剪辑点落在动作落点上：前一镜结尾姿态 = 后一镜起始姿态 | §2.1 尾段落点与下一镜起点对不齐 → 改动作描述 |
| 对话戏镜序 | 标准序：twoshot 建立 → OTS A（近景）→ OTS B（近景）→ reaction 特写；情绪升级时景别逐级"切近" | 非对话戏不适用 |

> OTS（过肩）：说话角色的过肩近景/中景，另一人肩/胸在前景略虚；是对话戏标准镜头，锁定 180° 轴线（§2.8）。"切近只是景别变化，不是换机位"（§2.1）同样适用。
> **允许越轴**：故意越轴（叙事意图明确）必须用一个中性插入（特写/远景/空镜）缓冲并占独立镜头，禁止无缓冲直接越轴（与 §2.8"故意反转"规则一致）。

## 3. @N 参考图约束语法

**格式**：`@序号=文件名（说明）`

**序号对应规则**：@N 序号必须与生成工具的参考图槽位顺序一致。

各工具参考图上限参考（撰写时注明，避免超出）：

| 工具 | 参考图上限 | 备注 |
|------|----------|------|
| Sora / Kling / 即梦 | 1~3 张 | start frame + 参考图 |
| Seedance | 最多 4 张 | @1~@4 |
| Midjourney | 最多 5 张 | `--sref` 语法 |
| 通用原则 | 建议 ≤ 3 张 | 超过 3 张一致性明显下降 |

**原则**：能少则少，核心参考图（角色 + 场景）优先，道具图其次。

**风格定板（style_ref）槽位规则（双层风格锁，2026-09-13）**：
- 场景图生成：@1=style_ref（文字写场景内容）
- 分镜批图：style_ref 显式占 1 槽（参考图 ≤5 时必带）
- 首帧/视频：默认不逐镜传 style_ref（风格沿 @N 参考链继承：角色图/场景图/尾帧均在风格锁下生成）；仅当工具槽位富余（无尾帧、无第二角色）时 style_ref 排在场景图之后显式附加
- 文字层无条件：所有图/视频提示词 ⑧ = 完整风格块逐字抄入（非关键词串），⑨ = 风格负向 + 镜头局部负向

### 3.5 `prev_shot_ref` 判断规则（agent 自动执行）

**触发条件**：相邻镜头 `shot_A` → `shot_B`，**三条全满足**才写入 `prev_shot_ref`：

| 条件 | 检查项 | 示例 |
|------|--------|------|
| 同场景 | `shot_A.scene_id == shot_B.scene_id` | 走廊→走廊 ✅，走廊→实验室 ❌ |
| 同角色 | `shot_A.character_refs` 与 `shot_B.character_refs` 有交集 | 林晨→林晨 ✅，林晨→老师 ❌ |
| 动作衔接 | `shot_A.video_action_desc` 结尾状态 与 `shot_B.first_frame_desc` 起始姿态 可衔接 | 低头→抬头 ✅，走动→闪回童年 ❌ |

**不触发的典型情况**（不写 `prev_shot_ref`）：
- 场景切换
- 时间跳跃/闪回
- 多角色镜头（前一镜头只有A角色，当前镜头A+B角色，B无参考来源）
- 角色姿态/表情剧变（前一帧姿态会误导当前镜头）

**ffmpeg 尾帧提取命令**（生成视频后执行）：
```bash
# 提取尾帧（用于下一镜头参考）
ffmpeg -i shot_001.mp4 -vf "select=gte(t,max-0.1)" -frames:v 1 frames/shot_001_last.png

# 提取中间帧（如需要）
ffmpeg -i shot_001.mp4 -ss 3 -frames:v 1 frames/shot_001_mid.png
```

### 多角色镜头 @N 槽位分配

| 优先级 | @N | 内容 | 说明 |
|--------|----|----|------|
| 1 | @1 | 主角身体图（base/base_version） | 最重要的角色（通常占比最大/有台词） |
| 2 | @2 | 主角头部卡（`c01_head*`） | **面部一致性主锚，不可降级**（面部特写/近景镜头必带） |
| 3 | @3 | 场景图 | 槽位挤爆时降级为文字描述 |
| 4 | @4 | 第二角色图 | 多人同框时第二重要角色（优先给其头部卡；槽位紧张仅保头部卡，身体写文字） |
| 5 | @5 | 尾帧 / 焦点道具图 | 不降级 |
| — | 文字 | 其他道具/角色 | 写进提示词文字，不占 @N 槽位 |

> 3 人以上同框：只给前 2 个角色传参考图（各含头部卡），其余角色通过文字描述（"第三角色：矮胖，戴眼镜，穿红色毛衣"）。
