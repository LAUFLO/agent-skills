## 1. 常见错误对照

| 错误 | 错误写法 | 正确写法 |
|------|---------|---------|
| 视频提示词写成静态 | "一个少女站在湖边" | "少女缓缓转身，裙摆扬起，镜头正面缓推至侧面，节奏放慢" |
| 角色特征缺失 | "一个男孩" | "黑色短发、银色发夹、左眼角泪痣、黑色校服外套"（全 anchors + variant 服饰），@1=c01_v1.png |
| 参考图未标注 | 提示词无 @N | 每段结尾加 `@1=xxx @2=xxx` |
| 场景图带人物 | 场景参考图里画了主角 | 场景图无人，或人物占比 < 20% |
| 风格不统一 | 有镜头"写实"有镜头"卡通" | 全集 `style_keywords` 统一写入所有提示词 |
| 首帧 = 视频终点 | 动作提示词描述的落点 = 首帧画面 | 首帧是起点，动作提示词描述"从起点到终点"的过程 |
| 多角色未标注 | 两人同框但未说明谁是谁 | `@1=角色A @2=角色B`，提示词里明确"A站左侧、B站右侧" |
| 静默改 base 图 | 定妆照确认后悄悄换图，前面已生成内容全失效 | **定稿后默认不改**。确需改二选一：① 全项目重生成（含该角色所有镜头失效，重跑）② 旧单元保留、新单元起用新图（在 `plan.md` 记一行变更，接受轻微漂移）；agent 不得静默换图，必须向用户宣告选择 |

## 3. 分镜验收标准（每镜首帧生成后自检）

生成每镜首帧后，agent 对照以下 5 项检查，全通过才标记 `review_state = approved`：

| 检查项 | 通过标准 | 常见失败 |
|--------|---------|---------|
| 故事 | 不看提示词，读者能说出这个镜头在讲什么 | 画面好看但动作不明 |
| 连续性 | 角色/服饰/道具/场景细节与参考图一致 | 面部/服装漂移 |
| 构图 | 一个可读主体 + 可用负空间 | 画面拥挤，无视觉焦点 |
| 动作就绪 | 起始姿态允许计划中的运动 | 手被遮住、动作无法衔接 |
| 剪辑就绪 | 屏幕方向/视线/景别与前后镜头可拼接 | 跳跃/重复角度 |

**验收后操作**：
- 全通过 → `review_state = approved`，进入视频生成
- 任一项失败 → `review_state = needs_revision`，修改提示词后重新生成
- 连续 2 次失败 → 检查参考图是否合适，可能需要重新生成参考图

### 资产图验收（参考图生成后自检，先于首帧）

生成 `assets_prompt.md` 的参考图后，先过 3 项再继续（成本 1 张图 vs 下游 75 张首帧）：

| 检查项 | 通过标准 |
|--------|---------|
| 锚点全量 | `feature_anchors` 每一项都数得出来（数一数，缺一个 = 不过）|
| 色板一致 | 与角色/场景 `color_palette` 色偏一致，无跑色 |
| 光源一致 | 场景图光源三要素与 `scenes[].lighting` 一致 |

不过关 → 改该资产提示词重出；定妆照不过关影响全剧（见 §1"静默改 base 图"规则）。

### 审阅状态流转

```
draft → needs_revision → approved → generating → final
  ↑           │
  └───────────┘（修改提示词后回到 draft）
```

| 状态 | 含义 | 触发条件 |
|------|------|---------|
| `draft` | 初始状态 | 提示词首次生成 |
| `needs_revision` | 验收未通过 | 5项检查任一项失败 |
| `approved` | 验收通过 | 5项检查全通过 |
| `generating` | 正在生成视频 | 用户开始执行 |
| `final` | 视频生成完成 | 视频文件已生成并验证 |

### 视频级验收（`generating` → `final` 前，含声音与 VFX）

视频生成后、标记 `final` 前，逐条检查：

- [ ] 台词起点与镜头台词起点 ±0.5s 对位
- [ ] BGM 让位点全部落在对白/转折镜头
- [ ] VFX 元素强度与镜头情绪一致；弱项（画面文字/logo、水面精确倒影）优先检查
- [ ] 分段拼接镜头（目标工具单段 < 镜头时长时）的接缝被连续 SFX 床覆盖
- [ ] 同角色音色规格与 `voice_profiles` 完全一致
- [ ] 不达标元素：该镜头选"重新 prompt"或后期合成（用 `sound_vfx.md` 该行的 fallback，或现场处理）

## 4. 流程优化（降低废片率 + 省成本）

### 4.1 覆盖率规划（Coverage）

关键场景同时生成**宽景 + 特写**一对，剪辑时有选择：

| 镜头类型 | 配对 | 用途 |
|---------|------|------|
| 对白场景 | 宽景（两人同框）+ 近景（A反应）+ 近景（B反应）| 剪辑时切换 |
| 动作场景 | 全景（动作全貌）+ 特写（关键细节）| 节奏切换 |
| 情感场景 | 中景（人物+环境）+ 大特写（眼睛/手）| 情绪强化 |

> 在 `plan.md` 中标注哪些镜头有配对，剪辑时优先使用配对镜头。

---

### 4.2 资产 Grid 策略（选优锁定）

角色/场景参考图**不直接用一个**，而是：

```
1. 生成 3 个选项（Grid 或三次独立生成）
2. 对比 3 个选项，选最准确的
3. 锁定选中项为参考图，删除其他
4. 后续所有镜头引用锁定项
```

> 图片生成成本低（3张 ≈ 1张视频的成本），选项多的阶段用预算换准确性。

---

### 4.3 Animatic 测试（生成视频前）

在生成视频前，先用**首帧静图**做节奏测试：

```bash
# 将首帧按镜头时长拼接成静图动画（animatic）
ffmpeg -framerate 1 -pattern_number 1 -i shot_%03d_first.png \
  -vf "zoompan=z=1:d=1:s=1280x720" \
  -r 24 animatic_episode_01.mp4
```

**检查项**：
- 节奏是否流畅（有没有"卡住"或"太快"的段落）
- 情绪弧线是否可读（只看画面，不看提示词，能否感受到情绪变化）
- 相邻镜头景别是否合理（有没有连续两个特写或连续两个远景）
- **镜间规则视觉复核**（对着首帧/分镜批图版逐场景查 `video_prompt_guide.md` §2.11 + 各 shot `stage` 字段）：
  - 30°/景别差：相邻两镜角度或景别至少差一级，无跳切感
  - 景别序列：升级处"切近"、退潮处"切远"，无连续同级景别
  - 对话戏镜序：twoshot→OTS→reaction 是否成立，OTS 前景肩位与 180° 轴线一致
  - 故意越轴处是否已用中性插入（特写/远景/空镜）缓冲
  - 站位一致：角色左右/前后关系与各 shot `stage` 字段及 §2.8 基线一致，无互换
  - 任一项不过 → 改 `script.json` / 首帧提示词后重新生成，不进入视频生成

> Animatic 发现问题后修改提示词，**不生成视频**（省成本）。

---

### 4.4 高危镜头草稿层（可选，set piece / 多人动作戏）

- 应用对象：set piece（`acts[].set_piece`）与多人动作戏——站位/动作方向一旦错了，精版首帧和视频全部作废
- 做法：精版首帧之前先出**一张草稿画风**（全图加"草稿分镜、粗糙线稿"字样）图，确认构图/占位/动作方向正确，再出精版
- 成本：该镜头图生成 ×2；只对高危镜头用，普通镜头直接出精版（分镜批图版 image_prompt_guide §5 已覆盖整场审阅，草稿层是逐镜加保险）

## 5. 完整示例（所有规则同时应用）

以下是一个 **6s 复杂表演镜头**的完整 `shot_NNN.md`，同时应用了 video_prompt_guide.md §1/§2 所有规则。agent 生成时以此为参考。

```markdown
# shot_012
**幕**：act_3 时间崩塌
**时长**：6s
**镜头**：平视，近景，缓推
**目的**：reaction（林晨发现怀表指针再次倒转）
**方向**：static（角色基本不动）
**情绪基调**：震惊 → 恐惧
**色板**：冷蓝 8000K，暗:亮 65:35

## 上下文（自动注入，勿手改）
- 风格：日系动画 / 2D赛璐珞 / 柔和光影 / 电影感
- 角色：林晨（黑色短发 / 银色发夹 / 左眼角泪痣 / 校服外套）
- 场景：实验室（夜晚，冷蓝日光灯从天花板上方，8000K，暗:亮 65:35）
- 道具：旧怀表（铜质，氧化发绿，玻璃裂纹，指针倒转）
- 参考图：
  - @1 = c01_v1.png（定妆照，校服）
  - @2 = s03_scene.png（实验室场景）
  - @3 = frames/shot_011_last.png（前一镜头尾帧）

## 首帧提示词（9 要素）
> ① 平视，近景，缓推
> ② 16:9
> ③ 冷蓝日光灯从天花板上方，8000K，暗:亮 65:35
> ④ 主色冷蓝，辅色微弱暖黄（远处走廊灯）
> ⑤ 主体居画面正中，怀表占画面下 1/4
> ⑥ 前景：怀表（特写级清晰）；中景：林晨胸部以上；背景：虚化实验台
> ⑦ 震惊
> ⑧ 日系2D赛璐珞动画风格
> ⑨ 无侧面机位，无夸张表情，无AI塑料感，无字幕

## 视频动作提示词
> [时间轴：2 段，对应"发现→恐惧"一个情绪转折]
>
> [0~3s]
> 动作：林晨低头看着怀表，指针开始倒转，他手指微颤
> 情绪：震惊（发现异常）
> 镜头：平视，近景，固定
>
> [3~6s]
> 动作：林晨猛地抬头，眼神锁定怀表，握表手收紧
> 情绪：恐惧（意识到后果）
> 镜头：平视，近景，极缓推近至面部特写
>
> [微表情（video_prompt_guide.md §2.3）]
> 眉间骤然收紧，眼睑微张，瞳孔放大，下唇轻颤，
> 喉部一次克制吞咽，手指指节绷起，握力收紧
>
> [物理真实感（video_prompt_guide.md §2.7）]
> 日光灯管轻微闪烁（不安暗示），怀表金属表面反射冷蓝光
>
> 【禁止】
> - 换机位 / 跳切 / 夸张表演（瞪眼/张嘴/摇头）
> - AI塑料感 / 皮肤过度光滑
> - 字幕 / 水印 / 屏幕文字

## 对白/旁白
- 无对白（纯视觉反应镜头）

## 状态
- review_state：draft

## 验收（生成首帧后自检）
- [x] 故事：不看提示词能说出"角色发现怀表异常"
- [x] 连续性：面部/发型/服饰与 c01_v1.png 一致
- [ ] 构图：主体居中 + 怀表清晰
- [ ] 动作就绪：低头状态可衔接"猛地抬头"
- [ ] 剪辑就绪：方向 static，与 shot_011/013 一致
```
