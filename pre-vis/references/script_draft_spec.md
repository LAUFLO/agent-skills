# 剧本草稿导出格式规范（script_draft_spec.md）

## 定位

- `episode_NN/script_draft.md` 是**人可读交付层**：一份可以通读、可以发给他人看的完整剧本文档
- **自动导出，不手工维护**：阶段 ① 收尾时由本单元 `script.json` + 场景卡按场景顺序导出（与 `plot_map.md` 同时机）；① 修订后重新导出
- **快照语义**：草稿 = "① 定稿时点 + 音色（0c 定死）"的剧情快照；**台词语气/表演规格不进草稿**（留 shot 文件，草稿只带音色注记，见 §1 台词注记格式）；③.5 遮名重写等改了台词 → 重导草稿
- 三层关系：场景卡 = 审核层（碎片化、快）/ `script.json` = 执行层（机器数据）/ `script_draft.md` = 交付层（连续可读）
- 蒸馏来源：`references/素材库/格式与改编/`（sw-format-adaptation：汉森/沃尔特/希克斯/菲尔德/霍克斯特）；本文件只管"导出格式"，页面级排版（Fountain/页数）不在此

---

## 1. 文件骨架（每单元一份，中文场号制）

```markdown
# [项目名] 第 NN 单元：[单元标题]
> [logline] / 类型 / 单元时长 / 字数预估（§5 字数链）

## 场号 [编号] INT./EXT. [地点] [日/夜]
[动作段落（§2 规则）]

人物名
（括注，≤3 词）
台词（音色注记：男声/女声 + 年龄档 + 1 个性征，如"男声，17岁，略哑偏低"——取 `series.json` `voice_profiles`，跨单元不变故草稿安全）

[声效/新出场人物：全大写或加粗，一稿内统一]
```

**场号规则**（汉森/行业通行稿）：
- `INT.`/`EXT.` + 地点 + 日夜；**从概括到具体**（"INT.，球场，更衣室——日"）；细节（日期钟点）写进动作段
- 换场依据：地点或时间转变、增减人物、改变戏剧目的 → 新场号
- **只写主场面**（master scene）：戏剧目的连续但跨多地点的戏写一个场号（客厅吵到卧室到落地窗仍是一场）；分解镜头是剪辑师的事
- 闪回：场号前缀 `闪回 -`（或 `BEGIN/END 闪回` 包夹），尽量少用

---

## 2. 动作段硬规则（汉森/沃尔特/希克斯）

- **现在时 + 主动语态**（"保罗带着乔"而非"乔被保罗带着"）
- 像列表不像描述：**只写摄影机能拍、演员能演的**（"她站在那儿思考着"拍不到 → 删）
- **删形容词副词**；先写时间/季节/天气，再写地点物理特征
- **永远不提摄影机**：无 CU/POV/叠化/"我们看到·听到"；用文本暗示镜头（场景标题=广角，旗帜=中景，人物走向麦克风=特写）
- 每场结尾天然是切，不写"切至"；"淡入"只在片首、"淡出"只在片尾
- 人物首次出现：姓名大写 + 性别年龄；**不写身高体重肤色**，用抽象特色动作形容（"干枯皱缩的脸像干掉的柿子"）
- 道具与合成音效**加粗**（提醒制片经理/录音师）；声效只写来源不可见的（雷声、电话铃、画外狗吠）
- 段间空行，"一页剧本不是一堵文字墙"

---

## 3. 对白与元素级约定

- 台词在人物名下左对齐；人物名大写；**不断页**（用动作或他人插话打断）
- **音色注记**（§1 骨架格式）：角色首次对白时附一行"（音色：…）"，取 `voice_profiles`；后续对白不再重复。**次要角色（无 voice_profiles）不附音色注记**，对白只写人物名 + 台词（执行层音轨随生成工具默认，见 plan.md 第五步）
- 括注 **≤3 词且只用动词**（微笑/紧张），99% 不需要；多人场面只写"对谁说"
- 不划线强调、不用惊叹号、省略号最多两次；不写方言音译；台词必须是一句话（不是呻吟哼哈）

| 元素 | 记号 | 规则 |
|------|------|------|
| 旁白/电话另一端/录音 | `(V.O.)` | 说话者**不在**场景空间内 |
| 画外（在场空间内、画面外） | `(O.S.)` | 隔壁房间、门外 |
| 对白被动作段打断后继续 | `(CONT'D)` | 同一人物名后 |
| 两人同时说话 | 双人对白，第二人名后 `^` | 并排两栏 |
| 下一场声音先入本场结尾 | `(PRE-LAP)` | |
| 蒙太奇 | `MONTAGE - 标题` … 每条 `--` … `END MONTAGE` | 先考虑避免 |
| 交叉剪辑 | `INTERCUT - 甲地 / 乙地` | 自由切换不重写场号 |
| 字幕 | `字幕：……` | 动作段内 |

## 4. 改编四问（输入素材是小说/原稿时，导出前定改写边界）

1. 原素材冲突在哪一层（个人/人际/社会）？
2. 影像化必须重新发明什么（内心戏 → 动作化、不可拍信息 → 可见/可听）？
3. 必须保留什么（戏核/关键细节/不可替代的台词）？
4. 删什么（"摄影机拍不到、演员演不了"的内容）？

> 菲尔德：把改编当原创——产物是"自成逻辑的影像作品"，不是原素材转录。

---

## 5. 字数链（体量预估，与"数字一致性链"互校）

- script_draft 字数 ≈ 单元时长 × 每分钟字数：**对白为主 370~400 字/分钟**；动作/反应多（悬疑、动作、单机位喜剧）270~300 字/分钟
- 与 `script.json` `total_duration_seconds` 反推偏差 >±20% → 回查场景卡/镜头数再重导
- 中文稿没有"页"标准，**禁用"一页=一分钟"**（那是 US Letter/Courier 制）；"字"是唯一体量单位
