## A-01 宫崎骏（吉卜力）
**风格定义**：自然主义 + 史诗感，角色小/环境大，手绘水彩质感
**⑧ 风格块**：吉卜力式手绘 2D，水彩晕染背景（云/水/风可见流动），角色占画面 <20%；色彩自然暖调（暖绿/金黄/天空蓝）；光线为自然光 + 云层透光（体积光）；构图大远景 + 层次景深（前景植物/中景角色/远景云）。
**英文关键词组**：Miyazaki Ghibli style, hand-painted watercolor backgrounds, flowing clouds water and wind, character small against vast environment, warm natural greens and golds, soft natural light through clouds, layered depth
**风格负向**：无 3D 渲染 / 无高饱和霓虹 / 无角色占满画面 / 无AI塑料感
**参考影视作品（调研笔记）**：
- 《龙猫》(1988, 吉卜力) — 手绘水彩背景：田野/小屋/石子路偏暖黄（温馨回忆感）；云 = 厚涂水彩流动体
  · 镜头① [巴士站雨夜段]：暖黄路灯 2700K + 冷蓝雨夜，车站占画面 1/3，背景田野全清
  · 镜头② [田野大远景]：角色占画面 <10%，草浪/云/光线流动 = 画面主语
  · 可取特征：①水彩云（笔触方向 + 透光边缘）②暖黄田野色板 ③角色小于环境 ④前景植物入画
- 《哈尔的移动城堡》(2004) — 同样是草地却用冷色调（梦幻宁静感，"色彩随情绪变"设计法）
  · 镜头① [森林段]：冷色草地（蓝绿主导），水彩流动，角色小
**风格定板参考图内容（每板 = 可完整粘贴提示词）**：

  16:9

- [ ] 云透光（光束 2~3 束，云边缘亮于云体）
- [ ] 角色若入画：占画面 <20%（环境是主语）
- [ ] 色板自然暖（田野段暖黄主导；冷调梦境段蓝绿主导，须有"水彩感"）
- [ ] 前景植物入画（虚化 1/4 画面）
- 失败标记：3D 渲染 / 高饱和霓虹 / 角色占满画面 / 平涂无笔触 → 回炉

### 参考槽位（S1~S9）
- S1 人物外观：头身比 5~6，朴实健康设计（非夸张大眼），五官简洁（鼻子 1 短线），表情温和档（微动作级）；参照：龙猫/千与千寻 角色（已证）
- S2 道具材质：植物/木质 = 水彩肌理（笔触方向），石/纸 = 细节可数（2~3 处）
- S3 运镜：缓慢横摇 + 长静镜（定性），镜头不跟角色（环境 = 主语）；参照：千与千寻 海上列车（已证）
- S4 拍摄/制作技法：24fps 手绘 + 水彩背景（云/水/风 = 手绘流动体，已证），无动态模糊
- S5 光色参数：自然光 5500K 顶侧光 / 黄昏 3500K 金橙（暖黄 70% + 草绿 20% + 点缀 10%）
- S6 VFX/粒子：风/雨/云 = 手绘笔触（非粒子模拟，已证），雨滴/雾有实体绘制
- S7 声音签名：静默仪式（海上列车 = 无 BGM 只留铁轨+水声，已证），环境床为主（风/水/鸟）
- S8 帧率/节奏：6~8s/镜（长静镜），慢节奏
- S9 多人站位：双人 = 大空间分离（大远景左 1/4 与右 1/4）；群像 = 散点（非对称排列）

## A-02 新海诚
**风格定义**：极度精细天空/光影 + 粒子特效（光斑/尘埃/花瓣），高饱和蓝橙
**⑧ 风格块**：新海诚式 2D 动画，天空与光影是画面重点：大面积渐变天空（多层云质），逆光轮廓光 + 镜头光晕，漂浮粒子（光斑/尘埃/花瓣）；色彩高饱和蓝橙互补；体积光透过云层；构图特写 + 大远景交替 + 对称。
**英文关键词组**：Makoto Shinkai style, ultra-detailed sky gradients, volumetric god rays, backlit rim light, floating dust particles and lens flare, high-saturation blue-orange complementary palette, symmetric wide shots
**风格负向**：无低饱和灰调 / 无平涂色块光 / 无硬阴影高反差 / 无AI塑料感
**参考影视作品（调研笔记）**：
- 《你的名字。》(2016, CoMix Wave) — 新海诚**亲绘天空/背景**（多层手绘云 + 渐变）；"黄昏之时"= 视觉题眼
  · 镜头① [黄昏之时段]：天空 6~8 层渐变（靛蓝→蓝紫→品红→橘橙），云透光边缘；剪影逆光 + 漂浮尘埃光斑（8~10 点）
  · 镜头② [彗星坠落段]：深蓝夜空 + 橙红彗星拖尾（光痕 5~8px），地面反光，暗:亮 70:30
  · 可取特征：①天空 6+ 层渐变 ②云透光 ③漂浮粒子 ④蓝橙互补 ⑤逆光轮廓光
- 《天气之子》(2019) — 雨景系统：玻璃雨滴 + 霓虹反射 + 云开瞬间
  · 镜头① [雨中东京段]：霓虹品红 + 青（积水镜面反射 2 层），玻璃雨滴前景占 1/4，暗:亮 60:40

- S5 光色参数：黄昏 3200K 橙红 + 5600K 靛蓝（天空 6~8 层渐变，已证）；夜戏 6500K + 3000K 点缀
- S6 VFX/粒子：漂浮粒子（尘埃光斑 8~15 点，2~5px，已证），云隙光束 2~4 束
- S7 声音签名：钢琴独奏 + 环境床（风/雨/水），静默仪式段（无 BGM）；cue 点 = 情绪转折帧
- S8 帧率/节奏：静帧 4~8s/镜（长静镜），转折瞬间 1~2s 快闪（定性）
- S9 多人站位：对称大远景双人（各居 1/3 与 2/3）；情绪顶点 = 单人特写交替（不双人对镜）

## A-03 今敏
**风格定义**：超现实空间转换 + 梦境逻辑 + 画面拼贴感
**⑧ 风格块**：今敏式超现实 2D，空间在镜头内连续转换（无剪切换场），梦境逻辑（现实与记忆重叠）；色彩高对比色块 + 局部单色（黑白/单红）；光线为舞台灯光感（聚光 + 硬阴影）；构图极端角度（俯拍/仰拍/旋转）+ 跳切。
**英文关键词组**：Satoshi Kon style, surreal seamless space transitions, dream logic with overlapping reality and memory, high-contrast color blocks with localized monochrome, stage-spotlight hard shadows, extreme angles and jump cuts
**风格负向**：无写实摄影 / 无自然光主导 / 无平滑过渡（须跳切/瞬间换场）/ 无AI塑料感
**参考影视作品（调研笔记）**：
- 《未麻的日记》(1997, 今敏/马越) — 技术：2D 手绘 + **一镜到底空间连续转换**（无剪切换场，镜头内空间变形）
  · 镜头① [舞台/镜头转换段]：空间在镜头内连续变形（舞台→走廊→房间 无剪切），极端角度（俯拍/仰拍 45°+），舞台聚光（光锥 1~2 个 + 硬阴影）
  · 可取特征：①空间连续转换 ②梦境拼贴（现实/记忆重叠）③极端角度 ④舞台聚光 ⑤跳切
- 《红辣椒》(2006) — 梦境段：高对比色块 + 局部单色 + 旋转机位
  · 镜头① [梦境段]：高对比色块（红/蓝/黄 3 色分区，每色 30%+），局部单色（单红画面 10%），旋转机位（5~10°/s）

  > 今敏式超现实 2D，旋转楼梯空镜（无人物）：极端角度（虫视 60°），舞台聚光（光锥 1 个 + 硬阴影 2 道）；高对比（暗:亮 70:30）；空间连续转换感（楼梯扭曲 10°）；无写实、无自然光、无平滑、无AI塑料感

### 参考槽位（S1~S9）
- S1 人物外观：7~8 头身（90s 风格化），眼夸张（瞳孔放大档），表情惊愕档（微动作级但瞬间放大）；参照：未麻的日记（已证）

- S6 VFX/粒子：无炫特效（梦境逻辑 = 剪辑手法，非 VFX）；像素化/电视噪点（媒介特效）
- S7 声音签名：电子/工业乐（梦境段 = 变调/倒放），突然静默（事件瞬间）
- S8 帧率/节奏：梦境段 1~3s/镜（快切），叙事段 4~6s/镜
- S9 多人站位：群像 = 散点 + 极端角度特写（主观视点），对峙 = 荷兰角 15° 双人

## A-04 大友克洋 / 押井守
**风格定义**：赛博朋克 + 写实机械，雨夜霓虹（写实向 2D 动画）
**⑧ 风格块**：写实向赛博朋克 2D 动画，机械细节写实（齿轮/管线/铆钉可见），雨夜霓虹（雨面反射 + 霓虹多源）；色彩深蓝 + 品红 + 橙色霓虹；光线为霓虹反射 + 雨雾散射；构图广角 + 浅景深（背景霓虹虚化成光斑）。

**风格负向**：无卡通造型 / 无明亮白天 / 无低饱和灰调（须霓虹高饱和）/ 无AI塑料感
**参考影视作品（调研笔记）**：
- 《阿基拉》(1988, 大友克洋/东京Movie) — 技术：写实向 2D 赛璐璐 + 机械细节（齿轮/管线/铆钉逐帧手绘）
