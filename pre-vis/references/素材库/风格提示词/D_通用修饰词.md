# §D 通用视觉修饰词（可扩写组合）

> 用法：主风格 + 2~3 个修饰词 = 项目 `style_keywords` 的修饰部分（路由见 `style_reference.md`）。
> 修饰词必须"可挂进风格块"：与主风格块冲突时，风格块优先（风格块锁主风格，修饰词只做微调）。
> 每个修饰词写成"可观察描述"，不写孤立形容词。

## 维度表（8 维，每维 2~6 个可挂选项）

| 维度 | 可选词（可挂进⑧的描述） |
|------|--------|
| 质感 | 胶片颗粒（2K 级，轻微光晕）/ 数字锐利 / 水彩晕染 / 油画厚涂肌理 / 墨笔飞白 / 3D 渲染（次表面散射皮肤）/ 定格质感（黏土不完美接缝）/ 网点纸（漫画印刷点）/ glitch 错位（像素撕裂）/ VHS 复古（扫描线+色偏+噪点） |
| 光影 | 丁达尔光束（体积光可见）/ 逆光剪影（主体边缘光）/ 顶光硬阴影（眉骨鼻下）/ 单光源低调（大面积暗部）/ 多源霓虹反射（雨面镜面）/ 月光冷光（4000~5600K）/ 烛光动态光（1800~2200K，跳动） |
| 景深 | 浅景深（背景虚化成色块）/ 深焦（全清，环境叙事）/ 选择性对焦（焦点转移）/ 前景遮挡（隔门窗拍摄） |
| 色彩 | 高饱和 / 低饱和（莫兰迪灰调）/ 单色主导（>60% 画面同一色系）/ 互补双色（橙青）/ 类似色 / 双色体系（主色+点缀色，点缀 <10%） |
| 年代感 | 80s 复古（霓虹+CRT 光斑）/ 90s（VHS 颗粒）/ 维多利亚哥特（铸铁+煤气灯）/ 60s 复古未来主义（圆润金属+拨杆仪表）/ 中世纪（石壁+铆甲+烛台） |
| 画幅 | 16:9 / 2.39:1 / 2:1 / 4:3 / 1:1 / 9:16 |
| 氛围 | 史诗感 / 孤独 / 温暖 / 紧张 / 梦境 / 压抑 / 希望（与镜头 emotional_register 联写，不单独使用） |
| 速度感 | 静止凝固 / 慢动作（局部延时感）/ 正常速度 / 高速模糊（运动残影）/ 时间倒流（逆行动作逻辑） |

## 负向模板库（⑨ 组合用）

**通用模板（所有项目必带）**：
> 无AI塑料感，无过度磨皮，无字幕水印，无屏幕文字

**按媒介加**（二选一）：
- 2D 动画项目：`+ 无3D渲染感、无油画厚涂肌理、无照片级写实皮肤`
- 写实/电影项目：`+ 无卡通夸张比例、无高饱和动画色板、无过度光斑`

**按风格族加**：
- 赛璐璐/平涂：`+ 无厚涂笔触、无渐变阴影（阴影必须是色块阶梯）`
- 水墨/仙侠：`+ 无霓虹色、无硬阴影高反差、无塑料CG感`
- 复古胶片：`+ 无锐利数字感、无现代物品（手机/现代建筑）`
- 暗黑哥特：`+ 无明快节奏配色、无高调照明、无甜美卡通感`
- 水彩/手绘：`+ 无硬边矢量线条、无均匀平涂色块`

## 组合示例（主风格 + 修饰词 ≤3）

- 日系2D赛璐璐 + [体积光束] + [低饱和双色体系] + [16:9]
- 暗黑中世纪 + [烛光动态光] + [单光源低调] + [深焦] + [2.39:1]
- 新海诚 + [胶片颗粒（轻微）] + [逆光剪影] + [16:9]

组合规则：质感/光影/色彩三维内互斥项不可同选（如"水彩晕染"与"数字锐利"互斥）；画幅/年代感不计入 3 个名额。
