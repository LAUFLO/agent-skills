## C-01 科幻（太空）
**风格定义**：太空科幻：金属质感 + 冷色调 + 巨大尺度 + 黑暗宇宙
**⑧ 风格块**：太空科幻风格，金属船体质感（拉丝/铆钉/磨损），冷色调（深蓝/冷白）主导；巨大尺度感（船体/星球占画面 60%+）；黑暗宇宙背景 + 点光源（舷灯/星体）；深焦大景深（全清环境叙事）。
**英文关键词组**：space sci-fi, brushed metal hulls with rivets, cold blue palette, massive scale, dark space background, point-source lights, deep focus
**风格负向**：无暖色调主导 / 无卡通造型 / 无明亮内景主导 / 无AI塑料感
**参考影视作品（调研笔记）**：
- 《星际穿越》(2014, 摄影 Hoyte van Hoytema / IMAX 70mm) — 技术：IMAX 实拍 + 太空写实（无炫光，飞船有重量感）
  · 镜头① [黑洞"卡冈图雅"段]：巨大尺度（星球占画面 60%+），冷白 + 黑宇宙，点光源（舷灯/星体 8~12 点），深焦大景深（全清）
  · 可取特征：①巨大尺度 ②冷色调（深蓝/冷白）③点光源 ④深焦 ⑤金属磨损质感
- 《普罗米修斯》(2012, 摄影 Daniel Remler) — 船内金属纹理 + 冷蓝内景
  · 镜头① [船内走廊段]：金属拉丝 + 铆钉 + 管线（磨损细节可读），冷蓝内景（4500K），硬光单光源

  16:9
**例图核对（checklist）**：
- [ ] 金属质感（放大看：拉丝/铆钉/磨损细节 ≥2 项可见）
- [ ] 巨大尺度（船体/星球占画面 50%+，**非**近景道具感）
- [ ] 冷色调（深蓝/冷白 占比 >70%，**非**暖色主导）
- [ ] 点光源（光源 ≤5 个，**非**均匀打光）
- [ ] 深焦（背景全清，**非**浅景深虚化）
- 失败标记：暖色调 / 卡通造型 / 明亮内景 / 浅景深 → 回炉

### 参考槽位（S1~S9）
- S1 人物外观：8~9 头身（写实），宇航服圆润 + 磨损（划痕 2~3 处），面部 = 透明面罩后可见（表情克制档）；参照：星际穿越 飞碟段（已证：摄影 Greig Fraser / IMAX）
- S2 道具材质：船体拉丝金属 + 铆钉（3~5 处），管线/仪表（细节可数 2~3 处），高光 = 点光源反射（单点）
- S3 运镜：固定 + 缓慢横摇；大尺度 ↔ 极特写交替（尺度反差）；参照：星际穿越 黑洞段
- S4 拍摄/制作技法：IMAX 大画幅（2.39:1）+ 胶片颗粒，深焦（全清）
- S5 光色参数：冷蓝 4500K 主导 + 点光源（舷灯 2~4 盏），暗:亮 70:30；色板深蓝 60% + 冷白 30% + 黑 10%
- S6 VFX/粒子：星尘/光点（5~10 点），飞船尾迹 = 光带 1~2 条（无爆炸粒子）
- S7 声音签名：低频电子 drone + 单音（太空 = 绝对静默规则，声音只来自舱内）
- S8 帧率/节奏：大远景 5~8s/镜（慢节奏），特写 3~4s/镜
- S9 多人站位：对话 = 船舱内（小密闭空间，与舱外大远景反差）；两人 = 同框左右（各占 1/3）

## C-02 科幻（赛博朋克）
**风格定义**：霓虹雨夜 + 密集城市 + 全息投影（品红/青/橙）
**⑧ 风格块**：赛博朋克风格，霓虹雨夜（雨面反射霓虹），密集立体城市（高低楼群 + 空中走廊），全息投影悬浮；色彩品红 + 青 + 橙三色；光线为霓虹多源反射 + 雨雾散射；广角 + 长焦压缩交替。
**英文关键词组**：cyberpunk, neon rain night, dense vertical city, holographic projections, magenta-cyan-orange palette, neon reflections on wet streets, volumetric fog, wide and telephoto alternation
**风格负向**：无明亮白天场景 / 无自然光主导 / 无低饱和灰调（须霓虹高饱和）/ 无AI塑料感
**参考影视作品（调研笔记）**：
- 《银翼杀手2049》(2017, 摄影 Roger Deakins) — 技术：球形镜头（无变形宽银幕眩光）+ 雾散光 + 单色主导色板
  · 镜头① [拉斯维加斯废墟段]：橙棕锈色（Tiffen 滤镜 Lee 790 Moroccan Pink + 105 Orange = 全片偏红褐），雾 2~3 层（丁达尔光束 3~5 束），建筑废弃（锈 + 沙）；暗:亮 60:40
  · 可取特征：①橙棕锈单色主导 ②雾散光 + 丁达尔 ③巨大废墟尺度 ④无眩光（球形镜头）
- 《银翼杀手》(1982, 摄影 Jordan Cronenweth) — 技术：变形宽银幕（anamorphic 横眩光）+ 雨夜霓虹
  · 镜头① [雨夜街段]：霓虹多源（品红 + 青 + 橙 3 色），雨面反射（镜像 2 层），雾 1~2 层，anamorphic 横眩光（光斑椭圆）；暗:亮 70:30
  · 可取特征：①霓虹 3 色（品/青/橙）②雨面反射 ③雾 + 眩光 ④高反差

- [ ] 密集立体城市（楼群 3 层 + 空中走廊 1~2 条）
- [ ] 暗:亮 ≥60:40

### 参考槽位（S1~S9）
- S1 人物外观：8~9 头身，机械义体（2~3 处，金属 + 发光点 1~2 点），头发湿感（雨）；参照：银翼杀手 雨夜段

- S5 光色参数：霓虹 3 色（品红 40% + 青 30% + 橙 20%），暗:亮 70:30
- S6 VFX/粒子：雨/雾 + 霓虹反射（光斑 8~12 个），全息 = 半透明悬浮（闪烁 1~2 次/s 定性）
- S7 声音签名：电子合成 ambient（drone）+ 雨滴/引擎低频；紧张段 = 合成器 pulse
- S8 帧率/节奏：氛围段 4~6s/镜，追逐段 2~4s/镜
- S9 多人站位：独行者 = 霓虹背景前的剪影（人物 <20%）；双人 = 雨街两侧（权力对比：干侧 vs 湿侧）

## C-03 奇幻（史诗）
**风格定义**：大尺度自然 + 魔法光效 + 古老建筑（金/绿/紫魔法色）
**⑧ 风格块**：史诗奇幻风格，大尺度自然景观（山脉/森林/海洋占画面 70%+），魔法光效（光粒子/符文/光柱），古老建筑（石材/雕纹）；色彩金 + 绿 + 紫（魔法色）；光线为魔法光 + 自然光混合；构图大远景 + 仰拍。
**英文关键词组**：epic fantasy, vast natural landscapes, magic light particles and runes, ancient stone architecture, gold-green-purple magic palette, combined magic and natural light, wide and low-angle shots
**风格负向**：无现代建筑 / 无卡通造型 / 无低饱和灰调 / 无AI塑料感
**参考影视作品（调研笔记）**：
- 《霍比特人：意外之旅》(2012, Weta，摄影 Jack Astin) — 技术：实景 + 微缩模型 + 数字森林；精灵森林 = 大尺度 + 魔法光
  · 镜头① [精灵森林段]：森林占画面 80%+（大尺度），魔法光（光点 20~30 个，金绿 2~5px），建筑（石雕/藤蔓）占 20%；暗:亮 40:60
  · 可取特征：①大尺度自然（森林/山脉 70%+）②魔法光点（金色/绿色）③古老石雕 ④仰拍
- 《指环王：护戒使者》(2001, 摄影 Andrew Leslie) — 瑞文戴尔 = 古老建筑 + 魔法光柱 + 仰拍
  · 镜头① [瑞文戴尔段]：建筑（石雕/木构 3 层以上）+ 魔法光柱（2~3 束，金白）；仰拍（建筑顶 1/3）；暗:亮 45:55

- S7 声音签名：全编制管弦（弦乐 + 铜管齐奏）+ 低频鼓（史诗段）；静谧段 = 单音弦乐

- S9 多人站位：群像 = 阶梯阵列（主角前排居中，2~3 层），对决 = 低角度双人（各居 1/4 与 3/4）

## C-04 恐怖
**风格定义**：暗光 + 不对称构图 + 影子 + 狭窄空间（冷绿/深蓝）
**⑧ 风格块**：恐怖风格，暗光（暗:亮 80:20），不对称构图（主体偏画面 1/3 边缘），大面积影子（影子占画面 40%+），狭窄空间（走廊/楼梯/地下室）；色彩冷绿/深蓝；单光源硬阴影；景深选择性对焦（前景清晰 + 背景模糊）。
**英文关键词组**：horror style, dark low-key lighting, asymmetric composition, large shadows, narrow claustrophobic spaces, cold green-blue palette, single hard light source, selective focus
**风格负向**：无明亮对称构图 / 无自然光主导 / 无明快色板 / 无AI塑料感
**参考影视作品（调研笔记）**：
- 《遗传厄运》(2018, 摄影 Patrik Åkerman) — 技术：自然主义恐怖（居家场景 + 低饱和），暗光但不"脏"
  · 镜头① [卧室段]：暗光（暗:亮 80:20），不对称构图（主体偏画面 1/3 边缘），影子占画面 40%+；冷绿/深蓝（低饱和）；单光源（台灯/窗光 1 盏）
  · 可取特征：①暗光 80:20 ②不对称 ③影子 40%+ ④冷绿/深蓝低饱和 ⑤狭窄空间
- 《招魂》(2013, 摄影 Simon Duggan) — 走廊段：单硬光 + 硬阴影 + 冷绿
  · 镜头① [走廊段]：单硬光源（走廊尽头 1 盏，2700K），硬阴影（墙面条纹），冷绿（暗调）
