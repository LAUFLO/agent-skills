## B-01 日系2D赛璐璐
**风格定义**：日系2D赛璐璐：干净描边 + 硬边阶梯阴影 + 精细手绘背景
**⑧ 风格块**：日系2D赛璐璐动画，角色为干净等粗黑描边，大圆眼带高光、鼻子简化成短线或点；身体与服饰阴影为 2~3 层硬边色块（无渐变喷枪）；背景写实精细，与扁平角色层形成对比；整体色彩中饱和干净，光影柔和自然。
**英文关键词组**：Japanese 2D anime cel shading, clean uniform ink lineart, large expressive eyes with gloss highlights, 2-3 tone hard-edged cel shading, detailed painted backgrounds, medium saturation, soft natural light
**风格负向**：无3D渲染感 / 无厚涂笔触 / 无照片级写实皮肤 / 无AI塑料感
**参考影视作品（调研笔记）**：
- 《紫罗兰永恒花园》(2018, 京都动画) — 技术：2D 赛璐璐 + **电影级背景**（背景美术精细度远超角色层，常做浅景深虚化；角色 2~3 层阶梯阴影）
  · 镜头① [修道院庭院段]：背景建筑/云层全清精细，角色 2 层硬边阴影（阴影色 = 固有色叠冷色），日光 5500K，暗:亮 30:70
  · 镜头② [夜窗烛光特写]：烛光 2200K 单光源，面部 1 层硬阴影 + 眼瞳多层高光（2~3 点白高光），背景全虚
  · 可取特征：①描边等粗黑线 ②阴影 2~3 层硬边色块（无喷枪渐变）③背景精细 + 浅景深 ④眼部高光 2~3 点
- 《鬼灭之刃》(2019, ufotable) — 技术：2D 赛璐璐 + **关键帧全特效手绘**（火/水/雷呼吸法特效逐帧手绘，非粒子）；战斗段"动画帧 + 静止帧"交替（抽帧感）
  · 镜头① [水之呼吸段]：水流特效 = 手绘蓝色块面 + 白色高光带（描边硬边），背景速度线放射状
  · 镜头② [炭治郎特写]：发丝高光 = 块面（非渐变），轮廓线在近镜处加粗
  · 可取特征：①高速动作下描边保持硬边 ②特效 = 手绘块面（有描边）③块面发丝高光 ④速度线
**风格定板参考图内容（每板 = 可完整粘贴提示词）**：

**例图核对（checklist）**：
- [ ] 描边等粗黑线（放大看：线条粗细均匀，非毛笔/矢量渐变线）
- [ ] 阴影为 2~3 层硬边色块（放大阴影边缘：无渐变/喷枪，色块边界清晰）
- [ ] 背景精细度 > 角色层（背景有建筑/云层细节可读）
- [ ] 角色眼部有 2~3 点白色高光（若出镜）
- [ ] 色板中饱和（非霓虹高饱和，非灰调）
- 失败标记：渐变喷枪阴影 / 3D 次表面散射皮肤 / 塑料感 → 回炉

### 参考槽位（S1~S9）
- S1 人物外观：头身比 6~8（TV 6~7 / 剧场 7~8），大圆眼 2 层高光，等粗细线 1~2px，皮肤 = 平涂 + 2~3 层硬边阴影，发丝 = 块面高光（2~4 点，无渐变），表情克制档（微动作级，不夸张）；参照：紫罗兰永恒花园 特写段（已证）
- S2 道具材质：道具同 2 层硬边阴影，高光单点白（2~3px），材质用色块不渐变；典型：怀表/信件/剑（金属 = 平涂 + 硬边高光 1 点）
- S3 运镜：固定机位为主，缓推/缓拉（慢速，2~3°/s 定性）；特写 ↔ 大远景交替；跟拍/手持少用；参照：紫罗兰永恒花园 对话段
- S4 拍摄/制作技法：24fps TV 16:9，on twos（12fps 关键帧）+ 关键帧/静止帧交替（抽帧感）（通则）；无动态模糊（2D）
- S5 光色参数：按场景（对照定板）；默认日戏 5500K 顶侧光，暗:亮 30:70（通则）；夜戏 2700~3000K 单光源
- S6 VFX/粒子：关键帧全手绘特效（火焰/水系 = 色块面 + 白色高光带，**非**粒子模拟）（已证：鬼灭 ufotable）
- S7 声音签名：情绪段静默（BGM 让位，只留环境床：风/水/room tone）；动作段鼓 + 弦重复动机；cue 点 = 关键帧同帧
- S8 帧率/节奏：对白 4~6s/镜，日常 3~5s/镜，动作 1~3s/镜（通则）
- S9 多人站位：180° 轴线；对话 = 中景双人 + 过肩近景；主角居画面中左/中右，权力位 = 更亮一侧

## B-02 新海诚风
**风格定义**：极度精细天空/光影 + 粒子特效 + 高饱和蓝橙，逆光为主
**⑧ 风格块**：新海诚式 2D 动画，天空与光影是画面重点：大面积渐变天空（多层云质），逆光轮廓光与镜头光晕，漂浮粒子（光斑/尘埃/花瓣）；色彩高饱和蓝橙互补，体积光透过云层；整体氛围安静、疏离、唯美。
**英文关键词组**：Makoto Shinkai style, ultra-detailed sky gradients, volumetric god rays, backlit rim light, floating dust particles and lens flare, high-saturation blue-orange complementary palette, quiet atmosphere
**风格负向**：无低饱和灰调 / 无平涂色块光 / 无硬阴影高反差 / 无AI塑料感
**参考影视作品（调研笔记）**：
- 《你的名字。》(2016, CoMix Wave) — 技术：新海诚**亲绘天空/背景**（多层手绘云 + 渐变，业界罕见）；"黄昏之时"是全片视觉题眼
  · 镜头① [黄昏之时段]：天空 = 蓝紫 → 橙红渐变（肉眼可辨 6~8 层色层），云带透光边缘；男女主角剪影逆光，粒子（尘埃光斑）漂浮
  · 镜头② [彗星坠落段]：深蓝夜空 + 橙红彗星拖尾，地面反光，暗:亮 70:30
  · 可取特征：①天空 6+ 层渐变（非平涂）②云透光边缘 ③漂浮粒子（光斑/尘埃）④蓝橙互补
- 《天气之子》(2019) — 雨景系统：玻璃雨滴（前景雨滴放大失焦）+ 城市霓虹反射 + 云开瞬间
  · 镜头① [雨中东京段]：霓虹（品红 + 青）在水面积分反射，暗:亮 60:40；玻璃雨滴前景占 1/4
  · 可取特征：①玻璃雨滴前景 ②霓虹品青反射 ③云开瞬间 = 全片最高光时刻
**风格定板参考图内容（每板 = 可完整粘贴提示词）**：
- 板1 [黄昏天空]（参照：你的名字。 黄昏之时）：
  > 新海诚式 2D 动画，黄昏天空大远景（无人物）：天空占画面上 2/3，渐变 6~8 层（靛蓝 → 蓝紫 → 品红 → 橘橙，自上而下）；云为手绘厚涂带透光边缘（云隙光 3~4 束）；地平线 1/3 处城市天际线剪影（逆光轮廓光）；空气中有漂浮尘埃光斑（8~10 点，2~5px）；色温 3200K 橙红区 + 5600K 靛蓝区并存；高饱和蓝橙互补；无低饱和灰调、无 3D 渲染、无平涂单色天空
  16:9
- 板2 [雨夜街道]（参照：天气之子 雨中东京）：
  > 新海诚式 2D 动画，雨夜都市街道空镜（无人物）：雨面反射霓虹（品红 + 青双色，积水镜面反射 2 层），前景玻璃雨滴 5~8 滴（放大失焦占画面 1/4）；霓虹招牌光源 6500K 冷 + 暖黄路灯 3000K，暗:亮 60:40；景深光斑（bokeh 圆点 10~15 个）；无低饱和、无厚涂油画、无AI塑料感
  16:9
**例图核对（checklist）**：
- [ ] 天空渐变层数 ≥5（放大看天空：色层可数，非单色 + 云贴图）
- [ ] 云有透光边缘（云边缘亮于云体，云隙可见光束）
- [ ] 漂浮粒子可见（光斑/尘埃 5 点以上，大小不一）
- [ ] 蓝橙互补色关系（冷蓝区与暖橙区同框，非单一色温）
- [ ] 逆光轮廓光（主体边缘有 1~2px 高光带）
- 失败标记：天空平涂 / 无粒子 / 灰调主导 / 硬阴影高反差 → 回炉

### 参考槽位（S1~S9）
- S1 人物外观：写实向 2D 7~8 头身，眼精细（2~3 层高光），发丝逐束高光（写实向），表情克制档（微动作级）；参照：你的名字。 特写段（已证）
- S2 道具材质：玻璃/雨滴/怀表 = 光泽材质（反射单点白 + 透明感），金属 = 细高光带 1~2 条
- S3 运镜：大远景 ↔ 特写交替 + 对称构图；固定 + 缓推为主（无手持跟拍）；参照：秒速5厘米 长静镜（已证：新海诚亲绘天空/背景）
- S4 拍摄/制作技法：24fps，胶片颗粒 2K 级（轻光晕），手绘厚涂背景（非矢量）；无速度线
- S5 光色参数：黄昏 3200K 橙红区 + 5600K 靛蓝区并存；夜戏 6500K 冷 + 3000K 暖点缀（暗:亮 60:40）
- S6 VFX/粒子：漂浮粒子（尘埃光斑 8~15 点，2~5px，手绘非模拟），云隙光束 2~4 束，花瓣/樱花飘落 10~20 片
- S7 声音签名：钢琴独奏 + 环境床（风/雨/水），静默仪式段（无 BGM 只留环境）；BGM 密度低（cue 点 = 情绪转折帧）
- S8 帧率/节奏：静帧 4~8s/镜（长静镜为主），转折瞬间可 1~2s 快闪；整体慢节奏（定性）
- S9 多人站位：对称大远景双人（两人分居画面 1/3 与 2/3，中景间隔大）；情绪顶点 = 单人特写交替（不双人对镜）

## B-03 少年漫
**风格定义**：少年漫动作风：速度线 + 动态角度 + 夸张动作 + 大嘴宽肩
**⑧ 风格块**：日系少年漫 2D 动画，干净粗描边 + 夸张肩宽头身比（约 7 头身以上）；动作段用速度线 + 放射状冲击背景 + 荷兰角；高反差（白底 + 硬阴影块面），点缀色限 1 色（红/橙）。
**英文关键词组**：shonen anime action, speed lines, radial impact bursts, dynamic Dutch angles, bold ink outlines, high-contrast cel shading, single accent color
**风格负向**：无柔焦光影 / 无厚涂 / 无低饱和灰调（少年漫 = 高反差快节奏）/ 无AI塑料感
**参考影视作品（调研笔记）**：
- 《一拳超人》S1 (2015, MAPPA) — 技术：2D 赛璐璐 + **关键帧（K 帧）全手绘**，普通帧简化；速度线/冲击放射线逐场景设计
  · 镜头① [怪人协会战段]：速度线占画面 30~50%（白底黑线放射），角色动作帧之间插静止关键帧（抽帧感）；冲击帧 = 单帧满屏放射线
  · 可取特征：①速度线放射构图 ②关键帧 + 静止帧交替 ③白底黑线 + 单点缀色
- 《我的英雄学院》(2016, Bones) — 登场段：广角仰拍 + 速度线向画面中心收拢（"登场 = 仰角 + 放射"公式）
**风格定板参考图内容（每板 = 可完整粘贴提示词）**：
- 板1 [冲击帧]（参照：一拳超人 冲击帧）：
  > 少年漫 2D 动作风：白底 + 黑色速度线自画面中心向四周放射（线宽 2~6px 不等，密度中心 >边缘）；中心冲击点为红色星芒（点缀色 <10%）；粗描边（线条 4~6px）；高反差（白底 + 纯黑线，暗:亮 15:85）；无柔焦、无灰调、无厚涂、无AI塑料感
  16:9
- 板2 [登场仰拍]（参照：我的英雄学院 登场段）：
  > 少年漫 2D 动作风：极低角度仰拍（虫视视角），建筑/角色轮廓向画面中心收拢，速度线沿收拢方向；天空留白 40%；点缀色（红/橙）占 <10%；粗描边 + 硬阴影块面；无柔光、无低饱和、无 3D 渲染
  16:9
**例图核对（checklist）**：
- [ ] 速度线/放射线可见（占画面 >20%）
- [ ] 高反差（白底占比 >50%，阴影为硬边块面）
- [ ] 描边粗（放大看：线条 4px 以上，非细线）
- [ ] 点缀色单一（红或橙之一，占比 <15%）
- [ ] 抽帧定格感（姿态像漫画分格，非流畅运动）
- 失败标记：柔焦光影 / 灰调主导 / 细线少女漫感 → 回炉

### 参考槽位（S1~S9）
- S1 人物外观：头身比 7+（夸张宽肩/窄腰），眼大嘴大（表情夸张档：大张嘴/瞪眼可），粗描边 3~6px；参照：一拳超人 K 帧（已证）
- S2 道具材质：武器/装备 = 色块平涂 + 硬边高光（单点白 3~5px），无渐变；典型：拳套/刀/护甲
- S3 运镜：荷兰角 5~15° + 极端角度（虫视/鸟瞰）；快推（沿运动方向 5°/s 定性）；参照：一拳超人 战斗段
- S4 拍摄/制作技法：on twos + 关键帧全手绘（K 帧精细/普通帧简化），速度线逐帧存在，smear 拉伸帧允许（2D）
- S5 光色参数：白底（亮 85%）+ 单点缀色（红或橙 <15%）；暗部 = 纯黑硬边块面
- S6 VFX/粒子：放射冲击线（白底黑线 12~20 条）+ 星芒爆点（手绘，非粒子模拟）
- S7 声音签名：冲击 SFX 单帧同步（"砰"= 帧准），鼓重复动机推进战斗；静段音乐稀疏（环境床为主）
- S8 帧率/节奏：动作 1~2s/镜（快切），对白 3~4s/镜；冲击帧 = 单帧满屏放射线（定格）
- S9 多人站位：对峙 = 双人侧影对向（低角度仰拍，两人分居画面 1/4 与 3/4）；攻击瞬间 = 放射线满屏（人物退为背景）

## B-04 少女漫
**风格定义**：少女漫：细线 + 大眼双高光 + 花朵/星星特效 + 柔光
**⑧ 风格块**：日系少女漫 2D 动画，细线大眼（瞳孔 2 层高光）+ 圆润五官；花朵/花瓣/星星/心形气泡特效层；柔光散射，粉紫色调，高明度低反差（亮:暗 80:20）。
**英文关键词组**：shoujo anime style, large sparkling eyes with double highlights, thin lineart, flower and star sparkles, pastel pink-purple palette, soft diffused lighting, high key low contrast
**风格负向**：无硬光源 / 无高反差暗部 / 无速度线战斗特效 / 无AI塑料感
**参考影视作品（调研笔记）**：
- 《水果篮子》(2019, TMS，尾崎美纪人设) — 技术：2D 赛璐璐 + **pastel 色板设计**（全片基调粉紫 + 柔光）；春景段花瓣特效逐场景手绘
  · 镜头① [春景走廊段]：花瓣 8~12 片飘落（前景 2~3 片放大虚焦），色板粉紫（亮:暗 80:20），柔光散射（无硬光源）
  · 可取特征：①细线（描边 1~2px）②pastel 粉紫 ③花瓣特效 ④柔光无硬阴影
