# 风格提示词（pre-vis 自产风格块库）

> 来源：pre-vis 自产（非外部 screenwriting-skills 蒸馏，不受外部版权注记约束）。
> 用途：0a-1 定全集风格 / 阶段② 风格定板生成 / 阶段③④ 风格一致性约束。
> 本目录是"查表执行层"：主流程不常驻加载，触发条件命中时 read 对应文件，结论回写 `series.json`。

## 风格块标准结构（7 基础字段 + S1~S9 参考槽位，每风格条目一条）

每个风格条目必须写全 7 字段，缺项视为未完成：

1. **风格定义**：一句话，"什么媒介 + 什么视觉系统"
2. **⑧ 风格块（可直接粘贴，中文）**：3~5 句，固定顺序
   `[媒介质感] → [色彩体系] → [光影语法] → [线条/机位] → [氛围]`；
   每句必须**可观察可核对**（允许写色温数值/暗亮比/占比/位置），禁模糊形容词（"电影感""有灵魂"）
3. **英文关键词组**：5~10 个，与中文块逐项对应（供 Midjourney 等海外工具）
4. **风格负向（⑨）**：3~5 条该风格专属禁项 + 必带 1 条通用项
   （"无AI塑料感、无照片级写实人脸"按项目媒介取其一）
5. **参考影视作品（调研笔记，2~4 部）**：每部按此结构——
   - `《片名》(年份，制作公司/导演)` + 技术属性一行（画幅 / 渲染管线 / 胶片工艺，如"3D 管线 + 2D 手绘厚涂背景""胶片抽帧"）
   - · 经典镜头①② [场景名]：镜头内容一句 + 可观察参数（光源/色温/暗亮比/色彩/线条质感/景深/机位，**尽量量化**：色温 K 值、占比 %、层数）
   - · 可取特征：3~5 条将写进风格块的要点
   - 质量要求：优先查"制作团队访谈 / 摄影杂志（ASC）/ VFX 案例"级来源；镜头写到**场景级**，不写全片平均
6. **风格定板参考图内容（每板 = 可完整粘贴提示词）**：2~3 板，每板写**一整段**完整提示词
   `主体 + 构图 + 机位（角度/焦距） + 光源三要素（位置/色温/暗亮比） + 色板（主色+点缀色占比） + 质感/粒子 + ⑧风格块 + ⑨负向`，80~150 字，末尾注画幅；
   板首标 `参照：《片名》镜头N`
7. **例图核对（checklist）**：4~6 条可观察项（标核验法：放大看 / 对板 / 目测色温）+ 失败标记（列 2~3 个"出现即回炉"的负例）

## 参考槽位 S1~S9（每条风格条目必含，按阶段查表取用）

每条条目在"例图核对"之后追加"参考槽位"块，S1~S9 各 1~3 行（量化参数 + 参考场景 + 来源标注）：
- **（已证）** = 有调研来源（制作团队访谈 / 摄影杂志 / VFX 案例）
- **（通则）** = 行业通则（帧率体系/类型惯例）
- **（定性）** = 无量化来源，只写方向**不写数字**（禁编造参数）

| 槽 | 内容 | 量化口径示例 |
|---|---|---|
| S1 人物外观 | 头身比/眼型/线宽/皮肤渲染/发丝高光/表情夸张度档 + **定妆照卡结构（双卡：身体三视图[颈上裁切] + 头部特写三格，2026-09-13）** | "8~9头身，眼 2 高光，线宽 1px，表情克制档；身体卡 2:1 横版 + 头部卡约 1:1.2（头部占格 40~60%）" |
| S2 道具材质 | 材质渲染语法 + 高光交互 + 该风格典型道具 | "锈蚀金属：高光单点 2~3px + 划痕可读；典型：烛台/铁链" |
| S3 运镜 | 2~4 条标志机位（角度/景别/运镜/速度）+ 参考场景 | "固定中景 + 缓慢横摇；特写↔大远景交替（无手持）" |
| S4 拍摄/制作技法 | 画幅/胶片/镜头类型（变形宽银幕 vs 球形）/抽帧/网点/速度线等 | "球形镜头无横眩光；2K 胶片颗粒（已证）" |
| S5 光色参数 | 光源位置/色温值/暗亮比/主辅色占比 | "单烛光 1800~2200K，暗:亮 80:20，黑 60%+烛橙 20%" |
| S6 VFX/粒子 | 特效语法（手绘 FX/粒子模拟/网点辉光/实拍烟）+ 粒子参数 | "特效全手绘笔触（非粒子模拟），光带 2~3 条宽 5~8px（已证）" |
| S7 声音签名 | BGM 气质（配器/节奏）+ 音效床 + 静默习惯 | "静默仪式段（无 BGM 只留风+水）" |
| S8 帧率/节奏 | 帧率约定（on ones/on twos/抽帧）+ 剪辑节奏 + 慢镜约定 | "on twos（12fps 抽帧感），冲击帧 1~2s/镜（已证）" |
| S9 多人站位 | 对话双人对镜/对峙/群像构图 + 站位运动约定 | "双人对镜严格中轴，两人同高同亮（闪灵 大堂段，已证）" |

## 风格基线与关键镜头风格表（series.json 回写字段，2026-09-13 定规，含三级锁强）

**`style_baseline`（0a-1 定风格时定，写进 series.json）**：取风格块 ⑧ + S1~S9 的"默认值"（每槽取最常用一条），**8 项各带 `lock` 标签（L1/L2/L3 锁级）**：

| 基线项 | 默认锁级 | 说明 |
|---|---|---|
| palette（色调/色板体系 + 饱和度范围） | **L1 全片硬锁** | 全片不变；moments 不许覆盖 |
| style（媒介/线条/材质语言 = ⑧ 块本身） | **L1** | 同上 |
| pace 帧率约定 / 画幅 | **L1** | 全片不变 |
| negative（风格负向） | **L1** | 全片不变 |
| lighting（光线语法基底档位） | **L2 幕级锁** | 幕内不变，幕末回退；0b 按幕声明档位（`episode_plan[].acts[].act_style`） |
| bgm（配器/气质）、sfx_bed（音效床） | **L2** | 同上 |
| fx（VFX 语法：手绘 FX/粒子） | **L2** | 同上 |
| camera / composition / blocking（运镜/构图/站位） | **L3 镜头级自由**（特殊风格可升 L2） | 各镜头按剧情现场判断，但取值在 L1/L2 画定的范围内 |

**三级锁强规则**：
- **L1 全片硬锁**：色调/媒介/帧率/画幅/负向 = 全片不变；`style_moments` 的 overrides **只允许动 L2/L3，动 L1 = 越权**——agent 必须停下，提请用户做项目级决策（`decision_log` + 全片重生成评估），不走 moment 通道
- **L2 幕级锁**：光线档/BGM 配器/音效床/VFX 语法 以幕为单位可切（如 act_1 塔外自然光档 → act_2 塔内烛光档），**幕内不变、幕末回退**；切换在 0b 声明 + 0a-3 moments 登记（basis = 幕基调）
- **L3 镜头级自由**：光源具体位置/色温值/暗亮比（在 L2 档位范围内，如 70:30±10）、景别/运镜/构图/站位/表情档/VFX 强度/节奏 = 各镜头按剧情现场判断（"自行判断"仅限 L3 层，且不得越出 L1/L2 边界）

**`style_moments[]`（0a-3/0b 定 set piece/beat 时标，写进 series.json）**：
`{moment_id, beat_ref, overrides:{仅 L2/L3 项，任意子集}, basis:对应情绪转折点}`
- 例：高潮 = L2 切"魔法光档" + L3 快推 + 粒子爆发 + BGM 爆发 cue；origin 闪回 = L3 抽帧 + L2 静默档
- 执行：**命中 moment 的镜头 = 基线 + 该 moment 覆盖项（仅限 L2/L3）；其余镜头 = 纯基线 + L3 剧情微调**（L1 永远不动）

**抽检分层（④ 滚动验收用）**：L1 项 = **批级硬检**（任一偏离 = 立即停批回滚，这是"像不像同一部片"的判据）；L2 项 = **幕末一致性检**；L3 项 = 逐镜 5 项验收（production_guide §3）

## 选片原则

- 选该片**"画面代表性最强"的幕/段，不是全片平均**（一部片视觉风格往往集中在某几幕），必须标注到幕/段
- 动画风格参考动画原片；导演风格参考 2~3 部代表作并具体到某幕；类型片参考"教科书级"画面（如赛博朋克 →《银翼杀手2049》沙漠段 +《银翼杀手1982》雨夜段）
- 可取特征必须"数得出来 / 看得见"；不可核对的描述一律不写

## 双层风格锁（执行规则，与 production_guide.md §2 一致）

| 层 | 约束 | 适用 |
|---|---|---|
| 文字层（无条件） | ⑧ 完整风格块 + ⑨ 风格负向，从本库对应块 + `series.json` 逐字抄入 | 所有图/视频提示词，禁止回退成 4~6 关键词 |
| 图像层（链式传递） | 风格定版图 = 链根（阶段② Wave 0 文生图）；场景图 @1=风格定版图；分镜批图显式带定版图；**首帧/视频不逐镜传定版图**——角色图/场景图/尾帧均在风格锁下生成，风格沿 @N 链继承，仅槽位富余时显式附加 | 按生成类型 |

- 风格定版图 = **项目级资产**：E01 阶段② 生成一次，E02~E04 引用不重出
- 批末风格漂移抽检基准 = **风格定版图**（抽 3~5 镜比对线条/色板/光影）
