## 使用纪律（重要）

- **主流程（阶段 0~④）不读本目录任何文件**。pre-vis 自己的 9 个 guide 已把方法论蒸馏进主流程。
- 只有以下触发条件命中时，才 read 对应文件：

| 触发任务 | 打开文件 | 说明 |
|---------|---------|------|
| 定调契诃夫式/小津式/继承之战式（反高潮、家常事件、群像权力战） | `风格样板/*` | 先开该样板的 SKILL.md 取"可复用模式"；逐场范例只查 reference |
| 判断某类项目要不要按"同型参照"排结构（悬疑/神经喜剧/纪实…） | `案例数据/*` | 找同类型片的结构参数对照 |
| 做喜剧短剧（笑点密度/困境机器/多机单机） | `喜剧规则/情景喜剧-SKILL.md` | 三层 premise-driven + 九困境 + 笑话力学 |
| 做国产长剧项目（45 分钟×N 集、字数体量、红线、分集大纲格式） | `国产剧/*` | 数据按 2014~2016 年，引用前核对现行规定 |
| 写/核对 `script_draft.md`（场号制细节、Fountain、改编四问全本） | `格式与改编/*` | 蒸馏版在主线 `script_draft_spec.md`；完整版面查表在此 |
| 用户明确不走三幕经典（主题后置、片段优先、类型承诺） | `学派替代路径/*` | 日本/韩法两派 |
| T1 蒸馏规则遇到"查表级细节"（原型表、逐场景节拍范例、引擎判据阈值） | `通用查表/*` | 按主题取对应 reference，勿通读 |

- 文内 `../sw-*/…` 相对链接与 `p0042` 式页码引用**指向原仓库文件/来源书**，本目录只保留正文，不跟原仓库联动维护。
