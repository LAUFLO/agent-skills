# 参考图资产台账（P2 模板，每片一份，镜头级更新）

| 编号 | 资产文件 | 职责 | 绑定 | 版本 | 在线 URL | 质检结论 | 喂给哪些镜 |
|---|---|---|---|---|---|---|---|
| P1-subj-v1 | subjects/portrait1-v1.png | 角色定妆（脸+服装+关键道具） | Portrait1 | v1 | <图像API返回URL> | 合格 | shot-01, 03 |
| S01-scene-v1-01 | scenes/scene-01-v1-01.png | 定场基准 | 场次01 | v1 | … | 合格 | shot-02 |

## 列规则
- **编号**：角色 `P<Portrait号>-subj-v<版本>`；场景 `S<场次号>-scene-v<版本>-<01~05>`
- **绑定**：一张图只承担一个主要职责；角色绑 Portrait 编号，场景绑场次编号，全片不复用改号
- **在线 URL**：Agnes 图像 API 返回的在线地址；P4 图生视频/关键帧直接喂此 URL，**不用本地文件、不用 Data URI**
- **质检结论**：由 subagent 视觉检查给出（合格 / 不合格+原因）；主会话不直接读图

## 规格提醒
- 定妆照：16:9，左侧三视图 + 右侧头部特写，背景纯色
- 场景图五件套：`-01` 基准 / `-02` 左转90° / `-03` 右转90° / `-04` 背面 / `-05` 俯视（前 4 张作参考生成俯视）
